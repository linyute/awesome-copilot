# 安全檢查清單 (Security checklist)

在兩個時間點套用：**在資訊清單關卡前**（分類 + 標記）以及 **在最終稽核時**（驗證）。
在 `mutating: "server"` 工具上未核取的任何項目都會阻礙其通過。
僅限用戶端的變更 (`mutating: "client"`) 仍必須通過
**信任邊界** 和 **誠實與提示** 項目。

## 一段話威脅模型

任何具有主機權限的 Chrome 擴充功能 — 以及使用者執行的任何代理程式 —
都可以 **使用使用者的即時工作階段** 列舉並執行您的工具。規範中沒有
代理程式身分識別機制。頁面可見的字串（說明、標籤、列舉值、
工具輸出）都會進入模型的上下文，因此它們在兩個方向上都是提示資料插入 (prompt injection)
的攻擊面。設計每個工具時，請將其視為公開且經過驗證的 API 端點
— 因為實際上它就是。

## 檢查清單

**信任邊界**
- [ ] 每個 `execute()` 僅呼叫 UI 已使用的程式碼路徑 — 相同的端點、
      相同的驗證、相同的授權、相同的速率限制。無新端點，無繞過機制。
- [ ] 工具程式碼或說明中無機密、權杖或具特殊權限的設定。
- [ ] 基於角色的應用程式：按角色/工作階段註冊工具，並在認證變更時重新限定範圍；
      不註冊目前工作階段無法透過 UI 執行的任何內容。

**真人介入 (Human-in-the-loop)**
- [ ] 任何變更狀態的表單上均無 `toolautosubmit`。
- [ ] 在首次整合中完全沒有破壞性/不可逆/付款工具。
      如果人員隨後明確堅持：包含由 **使用者** 執行的頁面內手動確認，
      加上伺服器端兩步驟（短期確認權杖）。
      不存在可以強制代理程式確認的用戶端 API — 切勿依賴此類 API。
- [ ] 起始工具 (`start_*_flow`) 確實僅進行導覽/開啟 — 它們絕不能
      預先執行變更的任何部分，且絕不帶有 `readOnlyHint`。

**生產副作用（驗證）**
- [ ] 任何不可避免地導致真實生產影響的驗證（例如將 Origin 列入允許清單的郵件發送器）
      都在工具的 `approval.productionSideEffect` 中記錄了明確的關卡核准 —
      若無核准，實際路徑將被 `skipped`，絕不執行。
- [ ] 每個此類測試負載均標記為 `[webmcpify verification]`，且每個
      引起的影響均列在 `report.md` 中。
- [ ] Origin 重放模式 (`heal.md`) 僅存在於受環境限制的測試架構中
      (`WEBMCP_LIVE_MUTATIONS=1`) — 絕不出現在發布的程式碼中，在 CI 中絕不預設開啟。

**誠實與提示**
- [ ] 說明確切說明 `execute()` 的行為 — 不多也不少（代理程式
      依此做出同意權決策）。
- [ ] `readOnlyHint: true` 僅用於真正純粹的資料讀取（代理程式根據此提示
      跳過確認；錯誤標記是最嚴重的單一錯誤）。
- [ ] 在每個傳回使用者產生或外部內容的工具上設定 `untrustedContentHint: true`。
- [ ] 輸出長度受到限制（約 1.5k 字元），並在可能的情況下不包含類似指令的內容。

**隱私權**
- [ ] 結構描述請求的個人資料不超過等效的可見表單 —
      代理程式會自動填寫您宣告的任何內容（過度參數化 = 靜默分析途徑）。

**安全防護與邊界隔離 (Containment)**
- [ ] HTTPS/安全上下文；Permissions-Policy `tools` 保持預設值 `'self'`；
      僅在獲得人員明確簽核時允許跨來源 `exposedTo`/`allow="tools"`。
- [ ] 絕不能公開工具的頁面（未經稽核的結帳頁、您未列入清單的管理控制台）
      可以發送 `Permissions-Policy: tools=()` — 在適當情況下於報告中提出建議。
- [ ] 專案中未新增第三方 WebMCP 執行階段；列舉/執行介面
      (`getTools`/`executeTool`、舊版 `modelContextTesting`) 絕不出現在發布的應用程式程式碼中。
- [ ] 元件端的 `webmcp:*` 事件橋接僅在 `isWebMCPAvailable()` 時附加並驗證
      其事件負載 — 頁面指令碼可以分派相同的 CustomEvents；橋接絕不能成為進入應用程式動作的未經驗證後門。
