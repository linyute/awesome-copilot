# 競爭對手廣告情報 (Competitor Ad Intelligence)

從 Meta 和 Google 擷取競爭對手的廣告、分析素材模式、逆向工程到達網頁漏斗，並產出完整的策略拆解 — 包含吸睛點 (hooks)、格式、定位策略、弱點及反制策略。

**核心原則：** 競爭對手的廣告組合是了解其成長策略的一扇窗。長期投放的廣告揭示了什麼能夠帶來轉換。新廣告揭示了他們正在測試什麼。到達網頁揭示了他們的定位策略。最優秀的廣告創意團隊會從已經有效的證據開始，然後進行差異化。

## 何時使用

- 「我的競爭對手正在投放哪些廣告？」
- 「拆解 [競爭對手] 的廣告策略」
- 「為我們的付費行銷活動尋找新的創意角度」
- 「逆向工程 [競爭對手] 的付費漏斗」
- 「在 [我們的領域] 中哪些吸睛點有效？」
- 「在我們推出產品之前審查廣告現況」
- 「找出 [競爭對手] 廣告策略中的弱點」
- 「在我們的類別中，哪種格式 — 影片、圖片、輪播 — 佔據主導地位？」

## 階段 0：資料收集 (Intake)

向使用者收集：

1. **競爭對手名稱 + 網域**（例如 `apollo.io`、`clay.run`）
2. **您的產品/網域** — 用於比較基準框架
3. **管道：** 僅 Meta、僅 Google，還是兩者兼具？（預設：兩者兼具）
4. **深度等級：**
   - **標準 (Standard)：** 廣告擷取 + 創意分析 + 到達網頁分析
   - **深度 (Deep)：** 標準 + 歷史比較 + 漏斗重建 + 反制策略
5. **產品類別** — 有助於建立分析框架
6. **已知競爭對手到達網頁？** — 在其廣告中已發現的任何 URL

## 階段 1：擷取 Meta 廣告

針對每個競爭對手網域，從 Meta 廣告檔案庫擷取廣告。

使用 `web_search` 在 Meta 廣告檔案庫中尋找競爭對手廣告（公開存取，無需 API 金鑰）：

```
web_search: site:facebook.com/ads/library "[competitor_name]"
web_search: "[competitor_name]" Meta Ad Library active ads
web_search: "[competitor_name]" facebook ads examples
```

您也可以直接造訪 Meta 廣告檔案庫：`https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=<competitor_name>`

如果您的代理程式支援，請在廣告檔案庫 URL 上使用 `fetch_webpage` 擷取廣告詳細資訊。

> **注意：** 用於 Meta 廣告檔案庫擷取的 Apify actor 雖然存在，但由於 Meta 的反爬蟲措施，截至 2026 年 4 月已不可靠。請使用 `web_search` 作為主要方法。

**針對每則廣告收集：**
- 廣告文案（標題 + 主要文字）
- 視覺類型（圖片 / 影片 / 輪播）
- 行動呼籲 (CTA) 按鈕文字
- 到達網頁 URL
- 投放時間長度（首次發現、仍在投放或已停止）
- 平台（Facebook、Instagram、Audience Network）
- 廣告變體（A/B 測試 — 相同的到達網頁，不同的素材）

## 階段 2：擷取 Google 廣告

針對每個競爭對手網域，從 Google 廣告透明度中心擷取廣告。

使用 `web_search` 在 Google 廣告透明度中心中尋找競爭對手廣告（公開存取）：

```
web_search: site:adstransparency.google.com "[competitor_name]"
web_search: "[competitor_name]" Google Ads transparency
web_search: "[competitor_name]" google search ads examples
```

您也可以直接造訪：`https://adstransparency.google.com/?search_text=<competitor_name>`

如果您的代理程式支援，請在透明度中心 URL 上使用 `fetch_webpage` 擷取廣告詳細資訊。

**針對每則廣告收集：**
- 標題變體（最多 3 個）
- 說明行
- 廣告類型（搜尋 / 多媒體 / YouTube / 購物）
- 到達網頁 URL
- 地理位置鎖定（若可見）

## 階段 3：分析創意模式

收集所有廣告後，執行結構化分析。

### 吸睛點模式分群 (Hook Pattern Clustering)

按吸睛點類型將所有廣告標題/開頭進行分組：

| 吸睛點類型 | 模式 | 範例 |
|-----------|---------|---------|
| **恐懼/損失** | 錯失機會或落後的風險 | "您的競爭對手已經在使用 AI SDR" |
| **成果** | 直接的結果承諾 | "在 30 天內將您的潛在客戶管道擴大 10 倍" |
| **提問** | 挑戰當前的假設 | "還在手動進行業務開發嗎？" |
| **社會證明** | 指名客戶或數字 | "加入 500+ 個使用 [產品] 的 B2B 團隊" |
| **逆向思維** | 挑戰傳統觀念 | "陌生開發信並沒有死。死的是你的文案。" |
| **同理心** | 證實他們的痛點 | "我們知道 SDR 的適應期非常痛苦" |
| **產品導向** | 功能作為吸睛點 | "[功能] 已上線 — 看看有什麼新功能" |

計算每個競爭對手使用每種吸睛點類型的廣告數量。這揭示了他們的主要訊息策略。

### 格式分佈

| 格式 | Meta | Google |
|--------|------|--------|
| 靜態圖片 | [N] | 不適用 |
| 影片 | [N] | [N] |
| 輪播 | [N] | 不適用 |
| 搜尋文字 | 不適用 | [N] |
| 多媒體橫幅 | 不適用 | [N] |

### CTA 分類法

列出發現的所有不重複 CTA。常見模式：
- **急迫性：** "免費開始"、"立即試用"、"今天就開始"
- **低門檻：** "了解運作方式"、"觀看示範"、"了解更多"
- **成果：** "預約示範"、"獲取免費審查"、"計算您的 ROI"

## 階段 4：到達網頁與漏斗分析

針對廣告中發現的每個不重複到達網頁 URL，擷取並分析：

```
fetch_webpage: [landing_page_url]
```

若 `fetch_webpage` 不可用，請使用 `curl`。

**針對每個到達網頁擷取：**
- **主要標題 (Hero headline)** — 是否與廣告承諾相符？
- **副標題** — 價值主張延伸
- **主要 CTA** — 他們推動的是什麼操作？（示範 / 免費試用 / 註冊 / 下載）
- **社會證明** — 標誌、見證、案例研究指標
- **價格可見性** — 價格是顯示還是隱藏？
- **表單欄位** — 他們要求填寫多少資訊？
- **頁面類型** — 一般首頁 / 專用 LP / 功能頁面 / 使用案例頁面
- **訊息匹配分數** — LP 兌現廣告承諾的程度如何？(1-10)

### 行銷活動分群

透過以下方式將所有廣告歸類為邏輯行銷活動：
- **到達網頁目的地** — 指向相同 URL 的廣告 = 相同的行銷活動
- **訊息主題** — 相似的文案切入角度 = 相同的策略佈局
- **受眾訊號** — 針對不同人物誌 (personas) 的不同文案

### 每個行銷活動的漏斗分析

針對每個行銷活動群組：

| 維度 | 分析 |
|-----------|----------|
| **策略意圖** | 此活動試圖達成什麼目標？（品牌認知 / 潛在客戶開發 / 免費試用 / 競爭取代） |
| **目標人物誌** | 此廣告對誰說話？（角色、痛點、階段） |
| **定位策略** | 他們聲稱什麼市場定位？ |
| **吸睛點策略** | 恐懼 / 成果 / 社會證明 / 逆向思維 / 產品導向 |
| **轉換路徑** | 廣告 → LP → CTA → [示範電話 / 免費試用 / 內容下載] |
| **持續時間訊號** | 這已經投放了多久？（越長 = 可能越有效） |
| **偵測到的 A/B 測試** | 連至相同 LP 的多個素材 = 正在進行積極測試 |

### 預算分配推斷

根據廣告數量與平台分佈，估計他們集中支出的領域：

| 平台 | 廣告數量 | 佔總數 % | 估計重點 |
|----------|----------|-----------|-----------------|
| Meta (Facebook) | [N] | [X%] | [品牌認知 / 再行銷] |
| Meta (Instagram) | [N] | [X%] | [視覺 / 年輕受眾] |
| Google 搜尋 | [N] | [X%] | [漏斗底層捕捉] |
| Google 多媒體 | [N] | [X%] | [品牌認知 / 再行銷] |
| YouTube | [N] | [X%] | [教育 / 品牌認知] |

## 階段 5：策略分析

### 創意缺口分析

跨所有競爭對手識別：

1. **無人投放的角度** — 競爭對手廣告中缺失的吸睛點類型 = 市場空白
2. **過度擁擠的角度** — 如果每個人都以「節省時間」開頭，請避免它或做得更具體
3. **格式機會** — 如果在您的領域中沒有人投放影片，它可能會脫穎而出
4. **未充分利用的證明** — 競爭對手是否避免使用您可以擁有的特定證明點？
5. **待測試的 CTA 模式** — 投放時間最長的廣告使用什麼 CTA？

### 弱點分析

識別每個競爭對手廣告策略中的弱點：

| 弱點類型 | 說明 |
|-------------------|-------------|
| **訊息與 LP 不匹配** | 廣告承諾一件事，LP 提供另一件事 |
| **單一人物誌相依性** | 所有廣告均針對相同人物誌 — 錯失其他受眾區隔 |
| **平台過度集中** | 重度依賴單一平台，在其他平台上缺失 |
| **無社會證明** | 廣告或 LP 缺乏可信度標記 |
| **CTA 薄弱** | 過早索取過多資訊（在提供價值前要求預約示範） |
| **泛用定位** | 任何人都能做出的主張 — 沒有差異化 |
| **素材陳舊** | 相同廣告數月未變更 — 疲勞風險 |

### 歷史比較（深度模式）

若存在其到達網頁的 Web Archive 資料：
- 他們的定位在過去 6-12 個月內是否有變更？
- 他們停用了哪些行銷活動？（可能失敗的項目）
- 他們擴大了哪些行銷活動？（可能成功的項目）
