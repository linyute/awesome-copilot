# 證據階梯 (Evidence ladder)

針對決策使用實際上最強力的證據。較高等級的證據對於
附近的主張而言，仍可能過期、無關或範圍過廣。

1. **直接的當前觀察** — 重現的行為、指令輸出、
   檢查過的產物或測量結果。
2. **具權威性的主要來源** — 官方規格、資料集、法規、
   文件、第一方存放庫或原創研究。
3. **獨立佐證** — 具有相異底層證據的稱職
   來源。
4. **明確推論** — 其前提與假設在圖中
   可見的結論。
5. **薄弱的代理指標** — 未確切執行該主張的相關指標、
   基準、軼事或測試。
6. **無支援的主張** — 沒有證據的自信、重複或
   精雕細琢的語言。

## 來源區域測試

在建立證據節點之前，回答：

- 確切依賴於哪一句話、表格、指令輸出、頁面、
  章節或行範圍？
- 它是否必然蘊含 (entail) 節點文字，還是僅討論相同的主題？
- 其日期與版本對於該主張是否合適？
- 該證據是獨立的，還是從另一個引用的來源複製的？
- 什麼上下文會反轉或縮小該解釋？

若無法定位確切區域，請建立 `unknown` 節點而非
證據節點。

## 邊線測試

| 關聯 | 使用時機 | 常見偽冒 |
| --- | --- | --- |
| `supports` | 來源增加了接受目標的理由 | 主題相似性 |
| `contradicts` | 兩者在相同範圍和條件下無法同時成立 | 不同的日期或母體 |
| `qualifies` | 來源縮小了範圍、強度或適用性 | 隱藏不方便的反面證據 |
| `missing` | 特定缺失的事實阻礙或可能反轉目標 | 泛用的「需要更多研究」 |
