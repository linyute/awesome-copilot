# 工作計畫範本 (Work Plan Template)

對於重大工作使用此範本。小型、明確的變更可以直接依據議題或請求進行。

```markdown
# [工作項目] - 計畫

## 目標

[一個可觀察的成果。]

## 情境

- 相關議題/請求：[連結或摘要]
- 存放庫指示：[連結]
- 重要限制：[清單]

## 範圍內

- [可交付成果]

## 範圍外

- [明確排除事項]

## 工作項目

1. [工作項目]
2. [工作項目]
3. [工作項目]

## 驗收條件

- [ ] [可觀察的行為]
- [ ] 相關存放庫檢查通過
- [ ] 當行為或運作發生變更時，文件/情境已更新

## 驗證

- 自動化：[指令或檢查]
- 手動：[重點情境，若有用]
- 獨立審查：必要 / 選用 / 不需要 - [原因]
- QA：必要 / 選用 / 不需要 - [原因]

## 風險與決策

- [風險或實質決策]

## 下一步行動

- [負責人與立即下一步]
```

## 進度筆記

對於長時間執行的工作，請保留簡短的進度筆記：

```markdown
# [工作項目] - 進度

- 已完成：[項目]
- 進行中：[項目]
- 受阻：[問題或無]
- 決策：[實質決策]
- 目前為止的驗證：[結果]
- 下一步行動：[特定行動]
```

## Dev 交接

```text
閱讀存放庫指示、PROJECT_BRIEF.md（如果存在）以及此計畫。
實作範圍內的工作、執行列出的驗證、在需要時更新持久情境，
並準備提取要求。請勿合併。
```
