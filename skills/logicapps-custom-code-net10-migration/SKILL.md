# Logic Apps 自訂程式碼 .NET 10 遷移

編輯前請先閱讀[遷移程序](references/migration.md)。請相對於此技能解析隨附檔案，而非目標儲存庫。僅輔助程式需要 Python 3.11+；切勿僅因啟用此技能而安裝相依性或啟動服務。

## 程序

1. 確認解決方案根目錄、自訂程式碼 `.csproj` 與 Logic Apps `host.json` 根目錄。
   推斷現有名稱／配置；僅在專案選擇或影響不明確時才詢問。
   閱讀儲存庫指引與受影響的設定，包含未提交的變更、
   繼承的建置／套件／SDK 設定、工作區與工具路徑。除非另外獲得授權以診斷建置失敗，
   否則請勿檢視 C# 內容。
2. 以預設的模擬執行（dry-run）模式執行隨附的輔助程式：

   ```powershell
   python "<skill root>\scripts\migrate.py" --root "<solution root>"
   ```

   使用 `--project "<csproj path>"` 在多個自訂程式碼專案中進行選擇。
   輔助程式會解析 `LogicAppFolderToPublish`；它不需要 `Functions`
   或 `LogicApps` 資料夾名稱。閱讀所有回報的阻礙項目／警告。在模擬執行模式下，
   它不會列印設定值，也不會寫入任何內容。
   預設編輯涵蓋框架／SDK／發佈／執行階段對齊，而非參考
   相依性對等。保留缺少的 Worker 套件與現有的偵錯程式設定。
   僅在要求／需要協調啟動時才使用 `--integrated-debug`。
3. 針對請求的遷移，使用相同的座標與 `--apply` 套用已審查的計畫。
   請勿在僅要求比較／計畫時套用。輔助程式會保護已變更的檔案，
   並在失敗時回滾其自身已完成的寫入；它不是不可分割的
   多檔案交易或永久備份。保留無關的使用者編輯。
4. 若輔助程式拒絕集中式／條件式／匯入的設定、較新的未經審查
   SDK 目標，或不熟悉的偵錯程式／配置，請勿繞過保護機制。閱讀
   所屬設定，當共用專案受影響時與使用者確認範圍，
   並使用儲存庫工具進行針對性的代理程式編輯。切勿宣稱輔助程式具備全面涵蓋範圍。
   針對受支援的配置重複執行模擬執行以檢查冪等性。
5. 使用儲存庫的建置／分析器與核准的套件來源進行驗證。使用
   VS Code 所選取的確切 SDK，而不僅是 PATH。驗證組件／相依性發佈
   與產生的本機函式 Metadata。在建置前檢視自訂建置／發佈 hooks，
   並為任何部署／網路影響取得單獨授權；
   可拋棄式複本並不會中和這些 hooks。在啟動主機或執行工作流程前，
   取得觸發程序／連接器影響的權限。若已安裝 Logic Apps
   執行階段技能／程序，請遵循之；否則請執行具備所有權意識的 VS Code
   啟動並驗證實際執行，而不僅是附加偵錯程式。
   若 SDK 的目錄掃描在全新建置時失敗，請使用 `--ensure-output-directory`
   重新執行輔助程式的模擬執行／套用，然後重試失敗的建置。請勿將此保護機制
   作為通用的框架需求引入。個別解決真正的缺少相依性錯誤；
   請勿僅為了符合範例而新增 Worker／HTTP／遙測套件。
6. 回報已變更的設定、模擬執行／套用／測試，並區分以下狀態：
   設定已遷移、建置已驗證、本機函式執行已驗證。
   清楚說明阻礙項目。務必回報後續部署先決條件：
   Azure 應用程式設定必須包含 `LOGIC_APPS_CUSTOMCODE_DOTNETVERSION=net10.0` 與
   `FUNCTIONS_INPROC_NET8_ENABLED=1`。透過 VS Code 中的 Logic Apps 延伸模組進行部署
   會複製這些設定；管線必須明確包含它們。
   僅有本機設定檔並無法設定 Azure。請勿部署、變更
   Azure 應用程式設定，或宣稱支援雲端／正式環境。

## 不變量

- 僅升級自訂程式碼函式庫；保留主機的 .NET 8 設定。
- 保留名稱、工作流程、連線、身份驗證、儲存體、無關相依性、
  工作區／工作慣例、註解與機密排除項目。
- 請勿新增僅供範例使用的 HTTP、遙測或框架參考。
- 請勿引入 `Program.cs` 或可執行的背景工作主機。函式庫的 `Main()` 不會
  自動執行；保留原始碼僅代表意圖，並非已驗證的 API 相容性。
- 設定輔助程式內部不進行 C# 重寫、SDK 安裝、還原、主機啟動、Azure 變更或永久性
  機密備份。
- 請勿私自降級套件、重寫共用套件管理、抑制
  還原／建置錯誤、將 .NET 10 DLL 複製到 `net472`，或捏造通過的檢查。
