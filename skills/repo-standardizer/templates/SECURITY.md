# 安全性政策

## 回報安全性弱點

請**勿**針對安全性弱點提出公開 Issue。

請改用非公開管道回報：

- 提交 [私密安全性諮詢 (Private Security Advisory)](https://github.com/OWNER/REPO/security/advisories/new)，或
- 傳送電子郵件給維護者（聯絡方式請見存放庫個人檔案）。

您應該會在 7 天內收到回覆。回報時請包含：

- 受影響的版本／Commit
- 重現步驟
- 影響程度說明

## 支援版本

| 版本 | 是否支援 |
|---------|-----------|
| latest  | ✅ |
| 較舊版本 | ❌（盡力提供協助） |

## 揭露程序

我們感謝負責任的弱點揭露。修復發布後，我們將在版本說明中向回報者致謝（除非要求匿名）。
