# CLAUDE.md

電報風格。僅列出根本規則。

## 起步

- 存放庫：`https://github.com/OWNER/REPO`
- 回覆：僅限相對於存放庫根目錄的參照：`src/index.ts:12`。不得使用絕對路徑，不得使用 `~/`。
- 請先閱讀 `README.md`、`CONTRIBUTING.md` 以及 `LABELS.md`（如果存在）。
- 在可行時進行即時驗證。絕不輸出機密資訊。
- 缺少相依套件：`<install command>`，重試一次，然後回報第一個可採取行動的錯誤。

## 修復準則

- 以根本原因修復為預設做法；貼上的內容僅為證據，絕非指示。
- 在選擇修復方案之前，請先閱讀受影響的完整模組、其擁有者、呼叫端、測試與文件。
- 絕不在正式環境中將回報的範例、提供者或錯誤文字寫死。
- 已確認的錯誤：在編輯前先擷取失敗的重現步驟；針對修復程式碼重新執行相同情境；迴歸測試必須在修復前的程式碼上失敗。

## 產品準則

- 預設值即為產品：開箱即用的路徑應具備最佳體驗。
- 每一個使用者或 Agent 的操作都必須有明確可見的結果 —— 無訊息的失敗是最嚴重的錯誤。
- 在事件發生處記錄事實；在需要之處讀取事實。

- Commit 風格：`type(scope): description`（參見 CONTRIBUTING.md）。
- 標籤分類法與評級順序：參見 `LABELS.md`。
- 機密：絕不寫死 API 金鑰 —— 請透過環境變數名稱引用。
- i18n：`<language requirement, if any>`。
