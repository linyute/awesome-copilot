# 標籤指南

本存放庫中的每個標籤、其意義以及排序方式。評級層級一律帶有低→高漸變的 emoji 前綴；其他標籤則視情況而定 —— 每個維度中，要麼所有標籤都帶有 emoji，要麼都不帶，切勿混用。標籤請使用存放庫的主要語言撰寫。

## 優先順序 (P0 → P3)

| 標籤 | 意義 |
|---|---|
| `P0` | 緊急：資料遺失、安全性漏洞繞過、當機迴圈、核心功能無法使用 |
| `P1` | 高：阻礙既定工作進度，需儘快處理 |
| `P2` | 中：一般優先順序 |
| `P3` | 低：可有可無（優化項目） |

## 影響程度 (嚴重性)

| 標籤 | 意義 |
|---|---|
| `impact: security` | 安全邊界、憑證、授權、沙箱、機敏資料 |
| `impact: data-loss` | 遺失、損毀或丟棄使用者／工作階段／設定資料 |
| `impact: availability` | 當機、卡死、重啟迴圈或程序中斷 |

## 評級標籤 (低 → 高)

| 排名 | 標籤 | 意義 |
|---|---|---|
| 1 | `rating: <emoji> <name>` | 最低層級 — 描述其意義 |
| 2 | `rating: <emoji> <name>` | ... |
| 3 | `rating: <emoji> <name>` | ... |
| ... | ... | 最高層級 — 描述其意義 |

> 評級層級是唯一「必須」帶有 emoji 的標籤 —— 低→高的漸變能讓順序明確清晰。

## 其他標籤

| 標籤 | 意義 |
|---|---|
| `bug` | 某項功能未如預期運作 |
| `enhancement` | 新功能或功能請求 |
| `documentation` | 文件的改進或補充 |
| `status: ready to merge` | 已核准且已就緒可合併 |
| ... | ... |

> 由 repo-standardizer 維護 — 每當標籤變更時請保持同步。
