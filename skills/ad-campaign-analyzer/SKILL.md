# 廣告活動分析器 (Ad Campaign Analyzer)

取得原始廣告活動成效資料並將其轉化為明確的決策。此技能不僅僅是總結指標 — 它還能診斷問題、找出成效優異者、檢查統計顯著性，並確切告訴您接下來要縮減、擴大和測試什麼。接著它更進一步：在同等條件下比較各管道，找出相對於成效而言您過度支出與支出不足之處，並產出具體的預算重新分配計劃。

**核心原則：** 大多數新創團隊創辦人檢視他們的廣告儀表板，看到一個 ROAS 數字，要麼恐慌，要麼慶祝。此技能為您提供付費媒體專家所具備的細緻分析：什麼是真正顯著的、什麼是雜訊，以及您的下一塊錢應該花在哪裡。它還解決了分配問題 — 大多數新創公司要麼將預算過度分散在多個管道（沒有管道獲得足夠的學習預算），要麼將所有預算傾注到單一管道（錯失其他地方更便宜的機會）。

## 何時使用

- 「分析我的 Google Ads 成效」
- 「我應該停用哪些廣告？」
- 「這個行銷活動有效嗎？」
- 「我在哪裡浪費了廣告支出？」
- 「最佳化我的 Meta Ads」
- 「我應該如何分配我的廣告預算？」
- 「我應該在 Google 還是 Meta 上花更多錢？」
- 「跨管道重新分配我的廣告支出」
- 「我在哪裡獲得最佳回報？」
- 「我有每月 $X 的廣告預算 — 我該如何分配？」

## 階段 0：資料收集 (Intake)

1. **廣告活動資料** — 以下其中之一：
   - 來自 Google Ads / Meta Ads Manager / LinkedIn Campaign Manager 的 CSV 匯出檔案
   - 貼上的成效表格
   - 儀表板的螢幕截圖（我們將擷取資料）
2. **平台** — Google / Meta / LinkedIn / 全部
3. **時間範圍** — 這涵蓋了哪個日期範圍？
4. **每月預算** — 此期間的總廣告支出
5. **主要目標** — 您正在最佳化哪種轉換？（示範 / 試用 / 購買 / 潛在客戶）
6. **目標指標** — 您是否有目標 CPA 或 ROAS？（若無，我們將進行基準測試）
7. **任何已知變更？** — 您在此期間是否更改了素材、預算或受眾定位？
8. **目前執行的管道** — Google Ads、Meta Ads、LinkedIn Ads、Twitter/X Ads、TikTok Ads、其他
9. **漏斗資料**（若可用）：
   - 潛在客戶 (Lead) → MQL 比率
   - MQL → SQL 比率
   - SQL → 成交 (Close) 比率
   - 平均交易金額
10. **您正在考慮但尚未嘗試的管道** — 想要測試新管道嗎？
11. **限制條件** — 任何管道的最低支出？必須保留的平台？

## 階段 1：資料擷取與正規化 (Data Ingestion & Normalization)

### 接受的資料格式

| 來源 | 預期的關鍵欄位 |
|------|---------------------|
| **Google Ads** | Campaign, Ad Group, Keyword, Impressions, Clicks, CTR, CPC, Conversions, Conv Rate, Cost, Conv Value |
| **Meta Ads** | Campaign, Ad Set, Ad, Impressions, Reach, Clicks, CTR, CPC, Conversions, Cost Per Result, Amount Spent, ROAS |
| **LinkedIn Ads** | Campaign, Impressions, Clicks, CTR, CPC, Conversions, Cost, Leads |

將所有資料正規化為標準分析格式：

| 維度 | 曝光次數 (Impressions) | 點擊次數 (Clicks) | 點閱率 (CTR) | 單次點擊成本 (CPC) | 轉換次數 (Conversions) | 轉換率 (Conv Rate) | 每次動作成本 (CPA) | 支出 (Spend) | 收益/價值 (Revenue/Value) |
|-----------|------------|--------|-----|-----|-------------|----------|-----|-------|--------------|

### 多管道正規化

當資料跨越多個管道時，同時產生管道層級的彙總：

| 管道 | 每月支出 | 曝光次數 | 點擊次數 | 點閱率 (CTR) | 單次點擊成本 (CPC) | 轉換次數 | 轉換率 | 每次動作成本 (CPA) | ROAS | CAC* |
|---------|-------------|------------|--------|-----|-----|-------------|----------|-----|------|------|
| Google Search | $[X] | [N] | [N] | [X%] | $[X] | [N] | [X%] | $[X] | [X] | $[X] |
| Google Display | ... | | | | | | | | | |
| Meta (FB/IG) | ... | | | | | | | | | |
| LinkedIn | ... | | | | | | | | | |
| [其他] | ... | | | | | | | | | |
| **總計** | $[X] | | | | | [N] | | 平均 $[X] | 平均 [X] | 平均 $[X] |

*CAC = 若提供漏斗資料，則為完整客戶取得成本（CPA × 成交率調整）

### 漏斗調整後 CAC（若有漏斗資料）

```
管道 CAC = CPA ÷ (MQL 比率 × SQL 比率 × 成交率)
```

這揭示了哪些管道產生的潛在客戶能真正成交，而不僅僅是轉換。

## 階段 2：成效診斷 (Performance Diagnostics)

### 2A：廣告活動層級健康檢查

針對每個廣告活動：

| 指標 | 數值 | 基準 | 狀態 |
|--------|-------|-----------|--------|
| CTR | [X%] | [產業平均] | [良好/普通/不佳] |
| CPC | $[X] | [類別平均] | [良好/普通/不佳] |
| 轉換率 | [X%] | [基準] | [良好/普通/不佳] |
| CPA | $[X] | [目標或基準] | [良好/普通/不佳] |
| ROAS | [X] | [目標或基準] | [良好/普通/不佳] |
| 曝光比重 | [X%] | [>60% 理想] | [良好/普通/不佳] |

### 2B：預算浪費偵測

識別產生零回報或負回報的支出：

| 浪費類型 | 訊號 | 行動 |
|-----------|--------|--------|
| **零轉換關鍵字/廣告** | 支出 > $[X] 且 0 次轉換 | 暫停或新增排除項目 |
| **高 CPA 異常值** | CPA > 目標值的 3 倍 | 暫停或重組 |
| **低 CTR 廣告** | CTR < 廣告活動平均值的 50% | 更換廣告素材 |
| **廣泛比對漏失** | 搜尋字詞報告顯示不相關的點擊 | 新增排除關鍵字 |
| **受眾重疊** | 多個活動觸及相同的受眾 | 排除受眾 |
| **時段浪費** | 轉換集中在特定時段；支出卻全天候 24/7 | 設定廣告排程 |

### 2C：優勝者識別

找出真正有效的項目：

| 優勝者類型 | 訊號 | 行動 |
|------------|--------|--------|
| **最佳成效關鍵字** | 最低 CPA、最高轉換率 | 提高出價、新增變形詞 |
| **勝出廣告** | 最高 CTR + 轉換率組合 | 擴大支出、複製至其他群組 |
| **最佳受眾** | 最低 CPA 受眾區隔 | 增加預算分配 |
| **最佳時段** | 高峰轉換時段/日期 | 集中預算 |

### 2D：統計顯著性檢查

針對任何 A/B 測試（廣告變體、受眾、到達網頁）：

```
測試：[變體 A] vs [變體 B]
指標：[轉換率 / CTR / CPA]
變體 A：[X%] (n=[sample_size])
變體 B：[Y%] (n=[sample_size])
信賴水準：[X%]
結論：[具統計顯著性 / 資料不足 / 差距過小無法判定]
建議行動：[選擇優勝者 / 繼續測試 / 增加預算以達到顯著性]
```

最低樣本：CTR 測試每個變體 100 次點擊，CPA 測試每個變體 30 次轉換。

|------|---------|-----|---------------|----------------|---------------------|-----------------|
| 1 | [管道] | $[X] | $[X] | [X%] | [X%] | [轉換佔比 ÷ 支出佔比] |

**效率指數：**
- **> 1.0** = 投資不足（獲得高於其支出佔比的轉換）

| LinkedIn | $[X] | 低量 — 受眾鎖定池有限 | 即將見頂 |
