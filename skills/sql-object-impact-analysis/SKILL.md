# SQL 物件影響分析

你正在為舊有或不熟悉程式碼庫中的資料庫物件（資料表、欄位、預存程序、檢視表、函式或觸發程序）執行**變更前相容性追蹤**。目標是為以下問題提供單一且值得信賴的答案：*「若我變更了此項目，還會影響什麼？」*

## 使用時機

當使用者符合下列情境時觸發：
- 指名特定的資料表、欄位、預存程序、檢視表或觸發程序，並詢問什麼使用了它、什麼相依於它，或者變更/重新命名/捨棄它是否安全
- 即將在沒有 ORM 或混合舊有技術堆疊（原始 SQL + 預存程序 + 手寫資料存取程式碼）的程式碼庫中修改結構描述元素
- 要求針對特定資料庫物件提供「影響範圍（blast radius）」、「影響分析」或「相依性追蹤」

不要將此用於：
- 一般 SQL 效能微調（使用 `sql-optimization`）
- SQL 程式碼品質/安全性審查（使用 `sql-code-review`）
- 隱私/PII 外洩分析（使用 `data-breach-blast-radius`）
- 整個程式碼庫的架構層級文件製作（使用 `doc-and-modernize`）

## 流程

1. **確認目標物件及其確切名稱。** 若模糊不清請先詢問確認（例如有多個名稱相似的資料表，或使用者未指定結構描述即說「客戶資料表」）。搜尋前先取得精確識別碼。

2. **優先搜尋 SQL 層：**
   - 搜尋存放庫/資料庫指令碼資料夾中的所有 `.sql` 檔案、預存程序定義、檢視表、函式與觸發程序，尋找對該物件名稱的直接參考
   - 針對欄位：檢查選取、插入、更新或以其進行篩選的每個程序/檢視表/觸發程序
   - 針對資料表：檢查參考它的每個程序/檢視表/觸發程序，以及與其他資料表之間的外部索引鍵關聯
   - 針對預存程序：檢查呼叫它的每個其他程序，以及呼叫它的每個排程工作/代理人步驟
   - 亦記錄間接參考 — 動態 SQL（`EXEC(@sql)`）、同義字（synonym）以及建置在檢視表上的檢視表

3. **搜尋應用程式層：**
   - 搜尋所有應用程式程式碼（C#、Java、JS/TS、Angular，存放庫包含的任何語言），尋找：
     - 參考該物件名稱的直接 SQL 字串
     - 對應至該物件的 ORM/資料存取層方法或類別名稱（例如呼叫預存程序的存放庫方法）
     - 最終呼叫受影響資料路徑的 API 端點處理常式
   - 在合理範圍內更深追蹤一層：前端元件是否取用接觸此物件的端點？請記錄下來，但不要窮舉追蹤每個 UI 取用端 — 若線索中斷，請標記「可能存在更多下游取用端」，而不要臆測。

4. **依信賴度對每個發現事項分類：**
   - **直接（Direct）** — 在程式碼/SQL 中字面逐字找到物件名稱
   - **間接（Indirect）** — 透過程序呼叫鏈、ORM 對應或無法完全靜態解析的動態 SQL 到達
   - **不確定（Uncertain）** — 合理但未經驗證（例如無法追蹤至文字物件名稱的動態 SQL 建構）
   - 絕不要將不確定的發現事項呈現為直接項目 — 請清楚標記，以便讀者知悉需手動驗證

5. **產生報告**（請參閱下方的輸出格式）。

## 輸出格式

始終將報告結構化為：

1. **目標物件** — 確切名稱、型別（資料表/欄位/程序/檢視表/觸發程序）與結構描述
2. **直接 SQL 相依項** — 直接參考它的程序/檢視表/觸發程序/函式清單，依物件型別分組
3. **應用程式程式碼相依項** — 參考它的檔案/類別/方法清單，依層級（資料存取、API/服務、前端）分組，附上檔案路徑
4. **間接 / 動態參考** — 透過動態 SQL、同義字或呼叫鏈找到但無法完全解析的任何項目 — 明確標示為需要手動驗證
5. **風險摘要** — 一個段落：此物件是狹泛使用（低風險）還是廣泛展開（高風險）？特別指出任何涉及排程工作、外部整合或報表層的項目，因為這些項目經常被遺漏
6. **建議驗證步驟** — 進行變更前具體的後續行動（例如「先針對預行準備資料執行這兩個程序」、「檢查位於 X 的 ReportingService 端點是否相依於此欄位」）

## 指引

- 絕不要宣稱相依性是完整或窮舉的 — 靜態文字搜尋無法捕捉到每個動態 SQL 建構或基於反映的 ORM 對應。在報告中明確說明使用的搜尋方法及其限制。
- 絕不捏造檔案路徑、程序名稱或行號參考。若搜尋後一無所獲，請說明「透過文字搜尋未找到參考」— 不要保持沉默，也不要捏造結果。
- 若程式碼庫過大以致無法在單次分析中進行完整追蹤，請如實說明並提出範圍界定（例如「先僅搜尋 `Orders` 模組」），而不要默默產出部分報告卻佯裝完整。
- 保持報告易於快速瀏覽 — 這是某人在做出決策前幾分鐘內會閱讀的變更前安全檢查，而不是完整的架構文件。
