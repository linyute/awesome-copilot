# 已發布 Illustrator 工具的說明文件

在為隨附於 Illustrator 指令碼、CEP 擴充功能、外掛程式、MCP 伺服器或可下載資產的 README、說明頁面或小型說明文件網站撰寫內容時，請使用此大綱。使用者通常是在遇到問題時才會閱讀安裝說明文件，因此請先列出需求條件，並讓每個步驟皆可供查核驗證。

## 大綱

1. **名稱與一行用途說明**，接著附上結果的 GIF 或螢幕截圖。
2. **需求條件**：Illustrator 版本、作業系統以及任何其他所需項目（字型、用於 MCP 伺服器的 Node.js）。註明您在何版本上進行測試。
3. **相容性表格**（如下）。
4. **安裝**，依作業系統與安裝方式各自分節。
5. **首次執行**：從開啟工具到獲得第一個結果的簡短逐步解說，每當畫面發生變化時附上一張螢幕截圖。
6. **選項**：各項設定、其範圍及其效果，並在有助於理解之處附上小型的變更前後比對影像。
7. **疑難排解**：徵狀、原因、解決方式。
8. **解除安裝**。
9. **變更記錄**，最新的排在最前面。
10. **授權**與隨附資產的致謝名單。

## 依工具類型的安裝章節

**指令碼 (`.jsx`)**

1. 下載 `acme-grid-tool.jsx`。
2. 從檔案 > 指令碼 > 其他指令碼執行一次，或者將其複製到 Illustrator 的 `Presets/<locale>/Scripts` 資料夾並重新啟動 Illustrator，使其列在檔案 > 指令碼下。

**CEP 擴充功能 (已簽署的 ZXP)**

1. 下載 `acme-grid-tool-1.0.0.zxp`。
2. 使用 Adobe 的 Unified Plugin Installer Agent 安裝，或透過 Adobe Marketplace 上的商品頁面進行安裝（若有的話）。提供 Windows 的完整 UPIA 命令以及 macOS 的檔案位置（參閱 cep-extensions.md）。
3. 重新啟動 Illustrator，然後開啟視窗 > 擴充功能 > Acme Grid Tool。

**CEP 擴充功能 (開發用複本)**

1. 將擴充功能資料夾複製到個別使用者的 CEP extensions 資料夾中。
2. 針對該 CSXS 版本開啟 `PlayerDebugMode`（僅限開發機器），然後重新啟動 Illustrator。

**外掛程式 (`.aip`)**

1. 關閉 Illustrator。
2. 將適用於您作業系統的 `.aip` 複製到您自選的資料夾中，並在偏好設定 > 外掛程式與暫存磁碟 > 附加外掛程式資料夾下設定它，或者將其複製到 Illustrator 的 `Plug-ins` 資料夾中。
3. 啟動 Illustrator。

**MCP 伺服器**

1. 需求條件（執行階段版本）、安裝命令，以及針對每個受支援 AI 工具的 MCP 設定程式碼片段。
2. 每個工具的功能、它讀取與寫入的資料夾，以及它絕不會執行的動作。

## 螢幕截圖與 GIF

- 以 100% UI 縮放比例擷取，並裁切至面板或發生變化的區域。
- 使用包含預留位置內容的示範文件（Acme Corp 圖稿、`example.com` URL）；絕不使用客戶檔案或真實帳戶。
- 包含 3 到 8 幀、每幀 1 到 2 秒的 GIF 相比長篇螢幕錄影更能清楚展示結果。使用指令碼從 Illustrator 匯出這些畫格，使其與說明文件完全一致。
- 為每張影像提供說明其顯示內容的替代文字 (alt text)。

## 疑難排解表格

| 徵狀 | 原因 | 解決方式 |
| --- | --- | --- |
| 找不到選單項目 | 指令碼未放入 Scripts 資料夾，或 Illustrator 尚未重新啟動 | 移動檔案，重新啟動 Illustrator |
| 面板遺失或為空白 | 版本超出支援範圍，或是未簽署的組建 | 檢查相容性表格；安裝已簽署的 ZXP |
| 「未開啟任何文件」 | 該工具需要已開啟的文件 | 先開啟或建立一份文件 |

## 說明文件中的資料

說明文件為公開性質。請僅使用虛構人物、公司與路徑：Jane Doe、Acme Corp、`jane.doe@example.com`，在 Windows 上為 `C:\Users\<user>\...`，在 macOS 上為 `~/...`。切勿將真實文件、Creative Cloud 資料庫或檔案清單中的名稱複製到範例或螢幕截圖中。
