# 技能發佈稽核

為集合維護者提供發佈正確性報告：哪些預期技能遺漏、哪些非預期項目被暴露，以及哪些身份存在歧義。請從來源修訂版與目標取用者著手，而非假設可讀取的 SKILL.md 就會被正確發佈。

## 建立發佈合約

記錄來源修訂版、取用者／用戶端與版本、發佈配置以及請求的範圍。若特定用戶端規則會影響結果，請查閱該取用者的文件或實作；否則將結論標記為未驗證。

根據儲存庫實際的發佈原則與來源檔案建立預期的公開集合。區分作用中技能與封存、範本、測試 fixtures、產生的複本以及內部維護內容。來源集合可能包含刻意不發佈的 SKILL.md 檔案。現有的資訊清單本身可能已過時，因此請勿將其作為唯一的事實來源。

保留從每個身份到其來源路徑的對應關係。當雙方都公開儲存庫相對路徑時，優先使用該路徑；僅在名稱唯一且可比較時才使用名稱。若探索傳回對應至多個來源路徑的名稱，請回報該歧義，而非私自選擇或去重項目。

## 收集可比較的證據

- 使用與目標取用者相容的標準 YAML 剖析器剖析 frontmatter，然後驗證其支援的欄位型別。將格式錯誤的 YAML 與有效但未通過取用者結構描述的 YAML 區分開來。儲存庫的自訂剖析器通過並不代表與取用者相容。
- 檢視實際的發佈／資訊清單規則，包含路徑基底、明確項目、globs 以及排除或內部旗標。僅套用目標版本的語意：儲存庫的已棄用狀態欄位不一定會對安裝程式隱藏項目。
- 當有適當且經授權的指令可用時，取得同一來源修訂版的取用者探索／清單輸出。請先檢視其行為；名為 list 的指令並不一定就不會進行下載或寫入。優先使用隔離的簽出（checkout），並保留 stderr、結束狀態、版本、來源修訂版以及完整性／分頁限制。
- 當無法執行全新的取用者執行時，使用現有的擷取輸出。將其標記為歷史資料。若沒有可用的可比較取用者輸出，請完成靜態檢查並說明探索涵蓋範圍仍未驗證。

在收集發佈證據時，請勿執行技能主體或其輔助程式。安裝與端到端工作執行是獨立的驗證範圍；請勿重複安裝以製造使用次數。

## 協調身份，而非僅比較總數

當存在這些層級時，分別將預期的公開集合與資訊清單以及觀察到的探索結果進行比較。獨立回報遺漏的身份、非預期的身份、重複項目與剖析失敗。當資訊清單是實際的取用者輸入時，也請將資訊清單與探索結果進行比較。請勿假設不同安裝程式的資訊清單會控制直接的儲存庫掃描。

相等的總數可能會掩蓋不同的身份。例如，包含兩個作用中技能的預期集合與包含一個作用中技能加上一個範本的觀察集合，兩者長度皆為二，卻包含了一個遺漏與一個外洩。

若要進行具決定性的比較，請使用隨附的 [compare-discovery.mjs](scripts/compare-discovery.mjs) 搭配 Node.js 20 或更新版本；它不需要任何第三方套件。它接受兩個包含確切身份字串的 JSON 陣列。請根據上述證據建立這些輸入；它不會探索技能或推斷發佈原則。

```sh
node <skill-directory>/scripts/compare-discovery.mjs <expected.json> <observed.json>
```

JSON 報告包含原始／唯一計數、遺漏與非預期的身份，以及雙方的重複計數。結束代碼：0 代表確切的唯一比對成功，1 代表不相符或重複，2 代表無效輸入或 I/O 錯誤。它僅讀取提供的檔案並寫入其報告；絕不會呼叫安裝程式。

範例輸入與可稽核報告請參閱[完整範例](references/worked-example.md)。輔助程式的迴歸測試執行方式如下：

```sh
node --test <skill-directory>/scripts/compare-discovery.test.mjs
```

如需記錄在真實歷史擷取資料上的 Copilot 執行紀錄（包含確切輸入、輔助程式輸出與本機重播指令），請參閱 [Copilot 驗證報告](references/copilot-real-data-validation.md)。在驗證或重現此技能時請閱讀該報告；一般稽核則不需要。

## 報告與修復

針對每個發現，提供受影響的身份、來源／組態路徑與行號、觀察到的行為、可能原因以及最小修復方案。區分直接觀察與推論。當修改 Metadata 或資訊清單即足夠時，避免變更技能主體；保留無關的 Metadata 與授權資訊。

包含來源修訂版、取用者版本、預期／資訊清單／已探索計數、確切差異、實際執行的檢查以及驗證限制。允許零發現。請勿透過僅比較方便的子集，將無法使用或被截斷的探索結果轉化為成功的比對。

確切的探索比對僅確立了稽核範圍內的發佈涵蓋率。它並不代表技能已由即時 Copilot 工作階段載入、封裝的輔助程式可正常運作，或認證與外部服務可用。在進行經授權的修復後，請對修復後的修訂版重複相關的剖析與協調檢查，並回報變更內容。
