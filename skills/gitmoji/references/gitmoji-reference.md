# Gitmoji 參考資料 (Gitmoji Reference)

來自 [gitmoji.dev](https://gitmoji.dev/) 的完整官方 gitmoji 清單，按網站上顯示的順序排列。每個項目將一個表情符號（及其 `:shortcode:`）對應至其代表的變更意圖。

| 表情符號 | 短代碼 | 用於 |
|-------|-----------|---------|
| 🎨 | `:art:` | 改進程式碼結構 / 格式。 |
| ⚡️ | `:zap:` | 提升效能。 |
| 🔥 | `:fire:` | 移除程式碼或檔案。 |
| 🐛 | `:bug:` | 修復錯誤 (Bug)。 |
| 🚑️ | `:ambulance:` | 緊急修復 (Critical hotfix)。 |
| ✨ | `:sparkles:` | 引入新功能。 |
| 📝 | `:memo:` | 新增或更新文件。 |
| 🚀 | `:rocket:` | 部署相關項目。 |
| 💄 | `:lipstick:` | 新增或更新 UI 與樣式檔案。 |
| 🎉 | `:tada:` | 啟動專案。 |
| ✅ | `:white_check_mark:` | 新增、更新或通過測試。 |
| 🔒️ | `:lock:` | 修復安全性或隱私問題。 |
| 🔐 | `:closed_lock_with_key:` | 新增或更新機密。 |
| 🔖 | `:bookmark:` | 發佈 / 版本標籤。 |
| 🚨 | `:rotating_light:` | 修復編譯器 / Linter 警告。 |
| 🚧 | `:construction:` | 進行中的工作。 |
| 💚 | `:green_heart:` | 修復 CI 建構。 |
| ⬇️ | `:arrow_down:` | 降級相依性。 |
| ⬆️ | `:arrow_up:` | 升級相依性。 |
| 📌 | `:pushpin:` | 將相依性釘選到特定版本。 |
| 👷 | `:construction_worker:` | 新增或更新 CI 建構系統。 |
| 📈 | `:chart_with_upwards_trend:` | 新增或更新分析或追蹤程式碼。 |
| ♻️ | `:recycle:` | 重構程式碼。 |
| ➕ | `:heavy_plus_sign:` | 新增相依性。 |
| ➖ | `:heavy_minus_sign:` | 移除相依性。 |

| 👽️ | `:alien:` | 因外部 API 變更而更新程式碼。 |
| 🚚 | `:truck:` | 移動或重新命名資源（例如：檔案、路徑、路由）。 |
| 📄 | `:page_facing_up:` | 新增或更新授權條款。 |
