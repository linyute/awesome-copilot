# 自訂每日專注看板 (Customizing the Daily Focus Board)

## 主題設定
顏色位於 `assets/board.template.html` 的 `:root` CSS 區塊中
（`--ember`、`--good`、`--urgent`、背景）。預設外觀為溫暖/深色。標籤顏色：
`new`（綠色）、`deadline`（紅色）、`career`（紫色）— 複製 `.tagedit.<name>`
規則並將該名稱作為任務的 `tagc` 傳遞（使用純類別名稱：字母、數字、`-`、`_`）即可新增您自己的顏色。

## v2 — 以檔案為後盾的狀態（閉合代理程式迴圈）
v1 將進度儲存在瀏覽器 (`localStorage`) 中，代理程式無法將其讀回。為了讓
您的 AI 夥伴能夠*讀取*您的進度（例如撰寫您的一日結束日誌）並*寫入*它
（例如從聊天中「將設計文件標記為完成」），請改用 JSON 檔案作為看板的後盾：

- 看板將狀態寫入 `board-state.json`（透過微型本機端點或 File System Access
  API）而非 localStorage，並在載入時讀取它。
- 代理程式讀取/寫入該相同的 JSON。現在這是一個雙向迴圈：您進行對話，看板更新，
  代理程式可以從相同的單一事實來源總結這一天。

這是真正的*代理程式化 (agentic)* 版本 — 但它需要一個小型本機寫入路徑，因此它是一項
深思熟慮的升級，而非零設定的 v1。

## 選擇性 —「共用訊號」橋接（適用於多代理程式工作坊使用者）
看板的動能筆記與代理程式**進度訊號**具有相同的形式：帶有時間戳記的
已完成工作自我回報。如果您執行的多代理程式設定會發出 `.signals/*.json`
（例如每個工作單元一個訊號），您可以將這些訊號饋入動能摘要中，使*代理程式*工作
與*您的*工作共用一個時間軸 —「我的個人看板和我的代理團隊共用一個神經
系統。」

保持此功能為**選擇性加入 (opt-in)**。看板必須完全獨立存在，零工作坊相依性 —
這就是使其通用的原因。該橋接是進階使用者的額外功能，絕非必要條件。
