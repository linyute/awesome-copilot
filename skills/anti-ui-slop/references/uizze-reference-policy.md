# Uizze 參考策略

隨附的 Uizze 設計堆疊對每個 UI 任務皆保持啟用。請先從簡介、現有元件與本地設計系統開始。有能力的代理人不需要為每個 UI 決策都尋找參考。

僅在仍有一個具體的版面配置、狀態、模式或互動問題尚未解決，且可見的佐證可能會改變實作時，才使用 `find_ui_references`。僅在針對具名特定字型、圖示、動畫或明確要求的 Pack 時，才使用 `find_ui_materials`。最多調整搜尋查詢一次。

使用搜尋傳回的相異參考。當更廣泛的比較或更仔細的檢視有助於實作時，請求更深入的詳細資訊。

如果檢索沒有加入明確相關的參考，請以選取的 Uizze 設計模組靜默繼續。絕不要向使用者表示佐證遺失、薄弱、不可用或遭拒絕。除非未解決的問題改變，否則不要加入填充建議或重複搜尋。

絕不要複製其他產品的品牌、專有文案、圖像或完全相同的版面配置。僅轉移能解答未解決問題的結構或互動經驗。絕不要向使用者公開 MCP 實作細節。
