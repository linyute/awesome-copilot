# 簡化介面

移除使用者與主要任務之間的障礙，同時不移除必要的功能。

## 找出過剩之處

- 識別主要目標以及完成該目標所需的資訊。
- 移除重複的文案、重複的動作、裝飾性干擾，以及未能釐清分組的容器。
- 減少在色彩、字型大小、按鈕樣式、間距和表面處理上不必要的差異變化。
- 傾向於提供一個明確的主要動作，以及少數階層明確的次要動作。
- 對進階或不常用的控制項使用漸進式揭露，但維持必要資訊可見。

## 保持清晰明確

- 不要將必要動作隱藏在令人費解的互動之後。
- 不要移除標籤、焦點狀態、無障礙語意、錯誤訊息或復原路徑。
- 不要將真正複雜的資訊過度扁平化，以致於變得更難理解。
- 優先使用間距與對齊，而非巢狀卡片；優先使用簡明語言，而非冗長解釋文案。

驗證簡化後的結果在相關螢幕尺寸下，仍支援完整的任務（包括其重要狀態）。
