# 調整與潤飾現有介面

潤飾是改善既有的介面，而不是假借潤飾之名進行重新設計。除非使用者明確要求變更，否則請保留產品的視覺語言、內容、行為與範疇。

## 檢視真實結果

在可能的情況下渲染或執行介面。檢查具代表性的桌面與行動裝置尺寸（針對 Web 工作），或相關裝置類別（針對原生工作）。請以渲染後的結果進行評估，而非僅看原始程式碼。

優先處理最大的可觀察問題：

- 不清晰的階層架構或相互競爭的主要動作；
- 不一致的間距、排版、色彩、圓角半徑或圖示處理；
- 裁切、重疊、溢出、失真圖片或不協調的換行；
- 遺漏懸停、焦點、停用、載入中、空白、錯誤或成功回饋；
- 無法存取的控制項、微弱的對比度或不良的鍵盤行為；
- 與任務相互干擾的裝飾性雜訊。

以連貫的單一步驟修復相關問題。重複使用現有的 Token 與元件，避免推測性的清理，並保留原本運作正常之處。在修復完成後，再次確認已變更的介面。
