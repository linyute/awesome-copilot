# 產品與儀表板介面

產品 UI 應融入任務之中。當使用者需要快速操作並信任控制項時，熟悉感就是一項重要特性。

## 結構

- 讓目前位置、主要任務與下一個動作顯而易見。
- 使資訊密度符合工作需求。當使用者需要密集表格與緊湊控制項時，這類設計非常合適；裝飾性容器則不然。
- 優先使用標準導覽、表單、表格、標籤頁、選單與對話方塊，而非新奇的替代方案。
- 在加入邊框、卡片或背景之前，優先使用間距與對齊進行分組。
- 在整個介面上維持一致的元件詞彙。

## 狀態與行為

- 涵蓋產品可能達到的狀態：載入中、空白、錯誤、成功、停用、已選取、已展開，以及相關的復原狀態。
- 保持焦點可見、控制項具備標籤、對比度清晰可讀，以及目標易於操作。
- 防止重疊視窗與選單被捲動或溢出容器裁切。
- 僅在狀態變更與回饋時使用迅速的動態效果。不要為日常頁面載入精心編排過度動畫。
- 使響應式變更具備結構性：收合導覽、重排分組，並保留重要動作的存取途徑。

## 完成

以具代表性的尺寸使用介面。修復少數阻礙任務或破壞一致性的可觀察問題。不要重新設計所要求範疇之外運作正常的區域。
