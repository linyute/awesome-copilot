# 原生 iOS 介面

優先遵循產品現有的 iOS 慣例，其次遵循 Apple 平台慣例。原生介面在展現獨特性之前，應先讓人感到符合預期。

## 結構與控制項

- 使用導覽堆疊處理階層架構、使用標籤列處理少數頂層目的地，並使用工作表 (sheet) 處理自包含的任務。
- 保留邊緣滑動返回手勢與安全區域 (safe-area) 行為。
- 除非產品已有一套連貫的自訂系統，否則優先使用原生控制項、材質、選單、警示、工作表、選取器與文字行為。
- 保持觸控目標操作舒適、文字具延展性、標籤具備無障礙功能，且焦點順序合理。
- 考量鍵盤、長篇內容、動態字級 (dynamic type)、減少動態效果 (reduced motion)、深色模式與裝置邊距 (insets)。

## 狀態

納入任務所需的狀態：載入中、空白、錯誤、成功、權限遭拒、離線、停用，以及適用的復原狀態。回饋應當即時，且不應僅依賴色彩。

當模擬器或可執行的建置可用時，請檢視相關裝置類別一次，並修復可觀察到的裁切、重疊、違反安全區域、文字無法閱讀、導覽中斷或無法存取的控制項。當環境無法提供時，不要要求額外的工具。
