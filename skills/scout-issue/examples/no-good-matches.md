# 範例：找不到合適的匹配項目

*注意：以下的 issue 計數與編號僅為說明範例。*

## 使用者請求
```
幫我找一個編譯器子系統中適合新手的 Rust issue。無作用中 PR
（僅限未認領的工作），且過去 6 個月內應有活動紀錄。
```

- 已存在作用中的 PR

建議：

1. **放寬範圍**：「適合新手的 Rust issues」（不限於編譯器）
2. **擴大時間範圍**：「我可以在一週內完成的 issues」（不僅限於適合新手）
3. **不同領域**：「前端 Rust issues」或「文件 issues」

編譯器子系統需要深厚的專業知識。對於首次貢獻，請考慮：
- 其他領域中標記為「good first issue」的 issues
- 文件改進
- 測試涵蓋率補充
- 公用程式中的簡單錯誤修復
