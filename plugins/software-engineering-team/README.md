# Software Engineering Team 外掛程式

7 位專業 Agent，涵蓋從 UX 設計與架構到安全性與 DevOps 的完整軟體開發生命週期。

## 安裝

```bash
# 使用 Copilot CLI
copilot plugin install software-engineering-team@awesome-copilot
```

## 包含內容

### Agent

| Agent | 說明 |
|-------|-------------|
| `se-ux-ui-designer` | 針對 Figma 與設計工作流程提供待完成工作 (Jobs-to-be-Done) 分析、使用者旅程圖以及 UX 研究成果 |
| `se-technical-writer` | 技術撰寫專家，負責建立開發者文件、技術部落格、教學課程和教育內容 |
| `se-gitops-ci-specialist` | DevOps 專家，專注於 CI/CD 管線、部署除錯與 GitOps 工作流程，致力於使部署變得平淡且可靠 |
| `se-product-manager-advisor` | 產品管理指引，用於建立 GitHub issue、將商業價值與使用者需求對齊，並做出資料導向的產品決策 |
| `se-responsible-ai-code` | 負責任 AI 專家，透過偏見防範、協助工具相容性、倫理開發與包容性設計，確保 AI 造福所有人 |
| `se-system-architecture-reviewer` | 系統架構審查專家，具備良好架構框架 (Well-Architected frameworks)、設計驗證，以及針對 AI 與分散式系統的延展性分析能力 |
| `se-security-reviewer` | 著重安全性的程式碼審查專家，具備 OWASP Top 10、零信任 (Zero Trust)、LLM 安全性與企業安全性標準 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，該專案為社群推動的 GitHub Copilot 擴充套件集合。
