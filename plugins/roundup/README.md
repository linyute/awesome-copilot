# Roundup

學習您的溝通方式的狀態簡報產生器。

Roundup 會監看您在 GitHub、電子郵件、Teams、Slack 及其他工具中的工作動態，然後以您自己的語氣為您定義的任何目標對象起草狀態更新與簡報。

## 解決的問題

管理者與團隊負責人每週花費數小時從分散的來源彙整狀態更新：掃描 GitHub 中的 PR 活動、閱讀電子郵件討論串以獲取決策資訊、檢查 Teams 或 Slack 以獲取背景資訊，然後針對不同受眾以不同詳細程度重寫這一切。

撰寫這些更新所需的資料早已存在。主要工作在於收集並打包這些資料。Roundup 將收集與起草自動化。您只需把關品質並按下發送。

## 運作方式

**首次使用（5 分鐘）：** 執行設定 skill。它會詢問您的角色、您的目標對象，以及您團隊工作的進行場所。接著您貼上一或兩個您過去撰寫的更新範例。從這些範例中，它會學習您的格式、語氣、架構，以及您包含與省略的內容。

**之後每次使用：** 告訴 roundup 您要為哪個目標對象撰寫。它會從您設定的來源提取最新資料、進行跨來源彙整，並起草符合您風格的簡報。

## 安裝

```bash
copilot plugin install roundup@awesome-copilot
```

## 開始使用

### 首次設定

```
use roundup-setup
```

設定流程會引導您完成：
- 描述您的角色與團隊
- 貼上您過去撰寫的更新範例
- 定義您的目標對象（領導層、團隊、合作夥伴等）以及各方關注的重點
- 識別您團隊的工作與對話發生的場所

### 產生簡報

```
use roundup
```

或指定更具體的指令：

```
use roundup -- generate a leadership briefing covering this past week
```

```
use roundup -- draft a team update since Monday
```

## 包含內容

| Skill | 功能說明 |
|-------|-------------|
| `roundup-setup` | 互動式導引流程，學習您的風格、目標對象與資料來源 |
| `roundup` | 依需求根據您的設定檔產生簡報草稿 |

## 可提取資料的來源

Roundup 可配合您環境中可用的任何工具進行調整：

| 來源 | 尋找的內容 |
|--------|-------------------|
| GitHub | 您所設定存放庫中的 PR、Issue、Commit、檢閱活動 |
| M365 / WorkIQ | 電子郵件討論串、Teams 訊息、行事曆活動、共用文件 |
| Slack | 頻道訊息、討論串、公告 |
| Google Workspace | Gmail、Google 日曆、Google 雲端硬碟活動 |

在設定期間，roundup 會探索您擁有哪些工具的存取權限並進行相應設定。如果您稍後新增了新工具，只需重新執行設定以將其納入。

除了 Copilot CLI 環境中已設定的內容外，不需要額外的 API 金鑰或設定。

## 與眾不同之處

**從您的範例中學習。** roundup 不會強迫您套用固定範本，而是分析您的實際寫作風格並加以重現。您的簡報讀起來就像由您親自撰寫。

**支援您現有的任何工具。** 只有 GitHub？沒問題。完整的 M365 套件？太棒了。混合使用 Slack 與 Google？也能順暢運作。設定流程會探索您的環境並進行調整。

**多種目標對象，單一設定。** 定義具備不同詳細程度與格式的不同受眾設定檔。相同的底層資料，為各自產生不同的輸出。

**您的設定檔是可讀的檔案。** roundup 所學到的一切都儲存在 `~/.config/roundup/config.md` — 這是您可以隨時開啟、閱讀和手動編輯的純 Markdown 檔案。沒有晦澀難懂的設定或隱藏狀態。

## 重新設定

若要從頭開始重新設定：

```
use roundup-setup
```

在覆寫現有設定之前，它會先詢問確認。

若要進行微調，只需在任何文字編輯器中開啟 `~/.config/roundup/config.md`。該檔案以淺顯易懂的英文撰寫並按章節組織。您的變更將在下次執行時生效。
