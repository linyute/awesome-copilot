# 基於 MCP 的 M365 Agent 外掛程式

為 Microsoft 365 Copilot 建構具備 Model Context Protocol 整合之宣告式 Agent 的完整集合

## 安裝

```bash
# Using Copilot CLI
copilot plugin install mcp-m365-copilot@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/mcp-m365-copilot:mcp-create-declarative-agent` | mcp-create-declarative-agent |
| `/mcp-m365-copilot:mcp-create-adaptive-cards` | mcp-create-adaptive-cards |
| `/mcp-m365-copilot:mcp-deploy-manage-agents` | mcp-deploy-manage-agents |

### Agent

| Agent | 說明 |
|-------|-------------|
| `mcp-m365-agent-expert` | 為 Microsoft 365 Copilot 建構具備 Model Context Protocol 整合之基於 MCP 的宣告式 Agent 的專家助手 |

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個由社群驅動的 GitHub Copilot 擴充功能集合。
