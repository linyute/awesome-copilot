# CAST Imaging Agents 外掛程式

專門用於軟體分析、影響評估、結構品質諮詢以及使用 CAST Imaging 進行架構審查的專業 agent 完整集合。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install cast-imaging@awesome-copilot
```

## 包含內容

### Agent

| Agent | 說明 |
|-------|-------------|
| `cast-imaging-software-discovery` | 專門透過 CAST Imaging 進行靜態程式碼分析，以實現全方位軟體應用程式探索與架構對應的專業 agent |
| `cast-imaging-impact-analysis` | 專門使用 CAST Imaging 在軟體系統中進行全方位變更影響評估與風險分析的專業 agent |
| `cast-imaging-structural-quality-advisor` | 專門使用 CAST Imaging 識別、分析並提供程式碼品質問題補救指引的專業 agent |
