# Power BI 開發外掛程式

全方位的 Power BI 開發資源，包含資料模型化、DAX 最佳化、效能調校、視覺效果設計、安全性最佳做法，以及建構企業級 Power BI 解決方案的 DevOps/ALM 指引。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install power-bi-development@awesome-copilot
```

## 包含內容

### 命令 (斜線命令)

| 命令 | 描述 |
|---------|-------------|
| `/power-bi-development:power-bi-dax-optimization` | 全方位的 Power BI DAX 公式最佳化提示，用於提升 DAX 計算的效能、可讀性與可維護性。 |
| `/power-bi-development:power-bi-model-design-review` | 全方位的 Power BI 資料模型設計檢閱提示，用於評估模型架構、關聯性與最佳化機會。 |
| `/power-bi-development:power-bi-performance-troubleshooting` | 系統化的 Power BI 效能疑難排解提示，用於識別、診斷與解決 Power BI 模型、報表和查詢中的效能問題。 |
| `/power-bi-development:power-bi-report-design-consultation` | Power BI 報表視覺效果設計提示，用於建立有效、使用者易用且具無障礙特性的報表，並提供最佳圖表選擇與版面配置設計。 |

### Agents

| Agent | 描述 |
|-------|-------------|
| `power-bi-data-modeling-expert` | 專家級 Power BI 資料模型化指引，使用星狀結構原則、關聯性設計和 Microsoft 最佳做法，實現最佳模型效能與可用性。 |
| `power-bi-dax-expert` | 專家級 Power BI DAX 指引，使用 Microsoft 最佳做法以提升 DAX 公式與計算的效能、可讀性與可維護性。 |
| `power-bi-performance-expert` | 專家級 Power BI 效能最佳化指引，用於疑難排解、監視及改善 Power BI 模型、報表與查詢的效能。 |
| `power-bi-visualization-expert` | 專家級 Power BI 報表設計與視覺效果指引，使用 Microsoft 最佳做法以建立有效、高效能且易用的報表與儀表板。 |
