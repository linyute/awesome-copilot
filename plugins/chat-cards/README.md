# Chat Cards 外掛程式

GitHub Copilot 畫布的互動式卡片組。Agent 不會呈現整面文字，
而是透過即時的互動式卡片組進行視覺化解說：分頁方塊、
表格、SVG 圖表、表單、可折疊區段、編號大綱、轉譯的
Markdown 文件以及簡短短片。表單具備雙向功能：提交表單
會將數值傳回對話中作為 Agent 的下一個提示詞，因此卡片
在收集情境資訊與引導工作階段時，就如同呈現資訊一樣輕鬆自如。

## 安裝

```bash
copilot plugin install chat-cards@awesome-copilot
```

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。
