# Java MCP 伺服器開發外掛程式

使用官方 MCP Java SDK 2.x，以 Java 建置 Model Context Protocol (MCP) 伺服器。包含可產生伺服器專案的技能，以及提供指引的專家代理程式。

## 安裝

```bash
# 使用 Copilot CLI
copilot plugin install java-mcp-development@awesome-copilot
```

## 內容

### 命令（斜線命令）

| Command                                           | Description                                                                                                               |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `/java-mcp-development:java-mcp-server-generator` | 使用 MCP Java SDK 2.x、JUnit 測試和用戶端設定，產生 Java MCP 伺服器的 Maven 或 Gradle 專案 |

### 代理程式

| Agent             | Description                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| `java-mcp-expert` | 使用 MCP Java SDK 2.x 開發 Java Model Context Protocol (MCP) 伺服器的專家助理 |

## 原始碼

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。Awesome Copilot 是由社群維護的 GitHub Copilot 擴充功能集合。
