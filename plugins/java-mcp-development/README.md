# Java MCP 伺服器開發外掛程式

使用官方 MCP Java SDK 搭配響應式串流（reactive streams）與 Spring Boot 整合，在 Java 中建構 Model Context Protocol 伺服器的完整工具包。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install java-mcp-development@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/java-mcp-development:java-mcp-server-generator` | 使用官方 MCP Java SDK 搭配響應式串流以及可選的 Spring Boot 整合，在 Java 中產生完整的 Model Context Protocol 伺服器專案。 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `java-mcp-expert` | 在 Java 中使用響應式串流、官方 MCP Java SDK 與 Spring Boot 整合建構 Model Context Protocol 伺服器的專家協助。 |
