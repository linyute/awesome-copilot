# Sentry Triage 外掛程式

在 Copilot 畫布中掃描即時 Sentry 問題，依緊急程度分組，並移交
問題以進行追蹤或建立修復 PR。

## 安裝

```bash
copilot plugin install sentry-triage@awesome-copilot
```

## 1.4.0 版本更新

- **淺色模式。** 畫布採用專屬的淺色調色盤，搭配 Sentry 紫色點綴、易於辨識的狀態色彩，以及更柔和的輸入欄位陰影。無論主應用程式使用哪種色彩模式，畫布外觀都保持一致。

## 1.3.0 版本更新

- **更快速的問題詳細資料載入。** 問題清單以每頁 100 筆的方式擷取，且每頁各自排入 SDK 呼叫佇列，因此在掃描期間開啟問題，不必再等待單次耗時的 1000 筆請求完成。
- **問題深入檢視。** 詳細檢視會依需求載入問題資料，並以較低優先順序預先擷取資料。
- **更寬敞的版面配置。** 分類、標題與卡片之間留有更多間距，標題和摘要也更大。
- **趨勢圖表。** 每張卡片都會顯示 30 個資料點的事件迷你折線圖，總覽頁面則會顯示「事件隨時間變化」圖表。兩者皆使用 Sentry 已回傳的 `stats` 資料，因此不會增加 API 呼叫。
