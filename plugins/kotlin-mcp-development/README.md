# Kotlin MCP 伺服器開發外掛程式

使用官方 io.modelcontextprotocol:kotlin-sdk 函式庫在 Kotlin 中建構 Model Context Protocol (MCP) 伺服器的完整工具包。包含最佳做法指示、產生伺服器的提示，以及用於指引的專家聊天模式。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install kotlin-mcp-development@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/kotlin-mcp-development:kotlin-mcp-server-generator` | 使用官方 io.modelcontextprotocol:kotlin-sdk 函式庫產生具有適當結構、相依性與實作的完整 Kotlin MCP 伺服器專案。 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `kotlin-mcp-expert` | 使用官方 SDK 在 Kotlin 中建構 Model Context Protocol (MCP) 伺服器的專家助手。 |
