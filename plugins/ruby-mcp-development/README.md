# Ruby MCP 伺服器開發外掛程式

使用官方 MCP Ruby SDK gem 並具備 Rails 整合支援，在 Ruby 中建構 Model Context Protocol 伺服器的完整工具包。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install ruby-mcp-development@awesome-copilot
```

## 包含內容

### 命令 (斜線命令)

| 命令 | 描述 |
|---------|-------------|
| `/ruby-mcp-development:ruby-mcp-server-generator` | 使用官方 MCP Ruby SDK gem 在 Ruby 中產生完整的 Model Context Protocol 伺服器專案。 |

### Agents

| Agent | 描述 |
|-------|-------------|
| `ruby-mcp-expert` | 使用官方 MCP Ruby SDK gem 並結合 Rails 整合，在 Ruby 中建構 Model Context Protocol 伺服器的專家協助。 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群驅動的 GitHub Copilot 擴充功能集合。
