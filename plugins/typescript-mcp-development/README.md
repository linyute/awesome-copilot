# TypeScript MCP Server Development 外掛程式

使用官方 SDK 在 TypeScript/Node.js 中建構 Model Context Protocol (MCP) 伺服器的完整工具包。包含最佳做法指引、產生伺服器的提示，以及提供引導的專家對話模式。

## 安裝

```bash
# 使用 Copilot CLI
copilot plugin install typescript-mcp-development@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/typescript-mcp-development:typescript-mcp-server-generator` | 在 TypeScript 中產生具備工具、資源與適當設定的完整 MCP 伺服器專案 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `typescript-mcp-expert` | 在 TypeScript 中開發 Model Context Protocol (MCP) 伺服器的專家助理 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，該專案為社群推動的 GitHub Copilot 擴充套件集合。
