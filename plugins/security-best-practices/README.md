# 安全性與程式碼品質外掛程式

用於建構安全、可維護且高效能應用程式的安全性架構、無障礙指引、效能最佳化與程式碼品質最佳做法。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install security-best-practices@awesome-copilot
```

## 包含內容

### 命令 (斜線命令)

| 命令 | 描述 |
|---------|-------------|
| `/security-best-practices:ai-prompt-engineering-safety-review` | 全方位的 AI 提示工程安全性檢閱與改進提示。分析提示的安全性、偏見、安全漏洞與有效性，同時提供包含廣泛架構、測試方法論與教育內容的詳細改進建議。 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群驅動的 GitHub Copilot 擴充功能集合。
