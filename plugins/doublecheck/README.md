# Doublecheck

針對 AI 產生輸出的三層驗證管道。擷取可驗證的宣告、透過網路搜尋尋找來源、針對幻覺模式執行對抗式審查，並產生包含來源連結的結構化報告，以便人類在採取行動前進行驗證。

## 為何存在

AI 幻覺是模型層級的問題。沒有任何外掛模組可以解決它們。但是，透過讓驗證變得快速且結構化，可以減輕幻覺的*後果* — 依據捏造的引文採取行動、依賴編造的統計資料、引用不存在的判例法。

Doublecheck 不會告訴你什麼是真實的。它會從 AI 輸出中擷取所有可驗證的宣告、搜尋您可以獨立檢查的來源，並標記任何符合已知幻覺模式的內容。由您做出最終決定。

## 包含內容

| 元件 | 型別 | 說明 |
|-----------|------|-------------|
| `doublecheck` | 技能 | 核心驗證管道。執行三個層次並產生結構化報告。 |
| `Doublecheck` | 代理人 | 用於後續問題與更深入調查的互動式驗證模式。 |

## 三個層次

**層次 1：自我稽核。** 批判性地重新閱讀目標文字。擷取每個可驗證的宣告（事實、統計資料、引文、日期、因果斷言）。檢查內部矛盾。將宣告分類以供下游驗證。

**層次 2：來源驗證。** 針對每個擷取的宣告，執行網路搜尋以尋找支援或矛盾的證據。產生可點擊的 URL 以供獨立的人工作業審查。對引文進行額外的審查，這是幻覺風險最高的類別。

**層次 3：對抗式審查。** 完全轉換姿態 — 假設輸出包含錯誤並積極嘗試找出它們。對照幻覺模式檢查清單進行檢查：捏造的引文、無來源的統計資料、對不確定主題的自信具體性、時間混淆、過度概括以及缺少限定詞。

## 信心評等

每個宣告都會獲得最終評等：

| 評等 | 意義 |
|--------|---------|
| VERIFIED | 找到支援來源並已連結 |
| PLAUSIBLE | 與常識一致，未找到特定來源 |
| UNVERIFIED | 無法找到支援或矛盾的證據 |
| DISPUTED | 從可信來源找到矛盾的證據 |
| FABRICATION RISK | 符合幻覺模式（例如，在任何地方都找不到的引文） |

## 使用方式

### 持續模式（「一律開啟」）

啟用 doublecheck 模式後，它會在您的對話剩餘時間內保持開啟。Copilot 的每個實質回應都會在底部包含內嵌驗證摘要 — 每個事實宣告的信心評等與來源連結。

若要啟用，只需說：

```
use doublecheck
```

啟用後：
- 簡單的事實查閱與單一宣告的回答會自動取得內嵌驗證摘要
- 事實分析、法律分析、法規解釋、法規遵循指引以及包含判例引文或法定參考資料的內容會自動取得完整驗證報告而非內嵌摘要
- 若在內嵌驗證期間有任何宣告評為 DISPUTED 或 FABRICATION RISK，系統會自動產生完整報告
- 程式碼、創意寫作與隨意對話將會略過（驗證不適用）
- 您可以隨時透過說「full report」（或舊版片語「run full verification」）來要求對任何回應進行完整深入的驗證
- 隨時可以使用「turn off doublecheck」關閉它

隨時將其關閉：

```
turn off doublecheck
```

這是強烈建議在講求準確性的工作會議中使用的模式 — 法律研究、合規分析、法規指引、高階主管簡報。

### 單次驗證

若您不需要持續模式，可以視需求驗證特定文字：

```
use doublecheck to verify: [paste the text you want checked]
```

這會執行完整的三層管道，並產生詳細的驗證報告，其中每個宣告皆經過擷取、評等並標註來源。

### 互動式代理人模式

用於來回對話：

```
@doublecheck [paste text or describe what you want verified]
```

代理人模式讓您可以：
- 取得完整驗證報告
- 針對特定標記的宣告提出後續問題
- 要求更深入的調查（「dig deeper on C3」）
- 取得評估來源是否可信的協助

### 何時使用

- 在依據 AI 產生的法律分析、判例引文或法規指引採取行動之前
- 在將 AI 產生的統計資料或資料點納入文件之前
- 在審查將與客戶、領導層或外部各方分享的 AI 輸出時
- 在錯誤會帶來實質後果的領域（法律、醫療、金融、安全）中工作時
- 任何時候當您想到「我可能應該仔細複查這個」時

### 何時不應使用

- 用於「準確性」非目標的創意或主觀內容
- 用於程式碼審查（請改用程式碼專屬的審查工具）
- 作為主體領域專業知識的替代品 — 此工具可協助您更快驗證，但無法取代對該領域的了解

## 限制

請注意此工具無法執行的作業：

- **相同的模型，相同的偏見。** 驗證管道使用的模型型別可能與產生原始輸出的模型相同。它可以捕捉許多問題 — 尤其是結構化模式（如缺少引文）— 但它具有相同的基本知識限制。
- **網路搜尋並不全面。** 付費牆內容、最近發佈的資料與利基資料庫可能不會出現在搜尋結果中。宣告為「未驗證」可能意味著它位於付費牆後面，並不表示它是錯誤的。
- **VERIFIED 表示「找到來源」，而非「絕對正確」。** 來源本身可能錯誤、過時或被誤解。支援連結可加速您的驗證過程；但並未完成驗證。
- **工具無法捕捉它不知道自己不知道的內容。** 如果幻覺足夠複雜以通過所有三個層次，人類專家是您的最後一道防線。

誠實的定位：此工具提高了驗證品質的下限，並大幅減少了識別需要人工關注之宣告所需的時間。它並未提高上限。關鍵決策應始終包含人類領域專業知識。
