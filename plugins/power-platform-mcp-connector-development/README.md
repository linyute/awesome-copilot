# Power Platform MCP 連接器開發外掛程式

開發具備適用於 Microsoft Copilot Studio 的 Model Context Protocol 整合之 Power Platform 自訂連接器的完整工具包

## 安裝

```bash
# Using Copilot CLI
copilot plugin install power-platform-mcp-connector-development@awesome-copilot
```

## 包含內容

### 命令 (斜線命令)

| 命令 | 描述 |
|---------|-------------|
| `/power-platform-mcp-connector-development:power-platform-mcp-connector-suite` | 產生具備適用於 Copilot Studio 的 MCP 整合之完整 Power Platform 自訂連接器 — 包含結構描述產生、疑難排解與驗證 |
| `/power-platform-mcp-connector-development:mcp-copilot-studio-server-generator` | 產生專為 Copilot Studio 整合最佳化的完整 MCP 伺服器實作，具備適當的結構描述條件約束與可串流 HTTP 支援 |

### Agents

| Agent | 描述 |
|-------|-------------|
| `power-platform-mcp-integration-expert` | 具備適用於 Copilot Studio 的 MCP 整合之 Power Platform 自訂連接器開發專家 — 擁有結構描述、通訊協定與整合模式的全方位知識 |

## 來源
