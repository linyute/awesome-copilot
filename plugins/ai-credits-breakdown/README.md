# AI Credits Breakdown 外掛程式

精確檢視您自己的 GitHub Copilot AI 額度消耗去向：依日期、存放庫、模型、呼叫類型以及提示快取狀態統計費用，完全由您電腦上的 Copilot 遙測資料在私密環境下建構。

## 需求

- 支援畫布（canvas）的 GitHub Copilot 應用程式
- Node 22.13+（此擴充功能使用 `node:sqlite`，無法在舊版 Node 上載入）

## 安裝

```bash
copilot plugin install ai-credits-breakdown@awesome-copilot
```

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。請參閱 [擴充功能 README](../../extensions/ai-credits-breakdown/README.md) 了解其顯示內容以及精確讀取的資料。
