# Power Apps 元件架構 (PCF) 開發外掛程式

使用 Power Apps 元件架構為模型導向與畫布應用程式開發自訂程式碼元件的完整工具包

## 安裝

```bash
# Using Copilot CLI
copilot plugin install pcf-development@awesome-copilot
```
