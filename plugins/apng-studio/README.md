# Apng Studio 外掛程式

互動式 GitHub Copilot 應用程式畫布（app canvas）擴充功能，用於從影格建構動畫 PNG（APNG）檔案。繪製或上傳影格、調整各影格時間與合成、即時預覽、透過 QR code 傳送結果至手機，並匯出動畫 .png。

## 安裝

``bash
copilot plugin install apng-studio@awesome-copilot
``

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。
