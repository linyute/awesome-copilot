# CMS Development 外掛程式

用於內容管理系統（CMS）開發的工具組，涵蓋佈景主題、外掛程式、管理工具、媒體工作流程、Markdown 轉譯以及靜態匯出管線。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install cms-development@awesome-copilot
```

## 包含內容

### 技能

| 技能 | 說明 |
|-------|-------------|
| `content-management-systems` | 跨平台（如 WordPress、Shopify、Drupal、Webflow 和 AEM）的 CMS 專用工作流程。涵蓋佈景主題、外掛程式、管理面板、內容模型、媒體管線與靜態匯出。 |
| `markdown-to-html` | Markdown 轉譯、轉換與 HTML 輸出工作流程。 |
| `quasi-coder` | 解讀網頁設計描述，並從速記、準程式碼（quasi-code）和自然語言描述中實作程式碼。 |
| `web-coder` | CMS 任務通常依賴的前端、瀏覽器與 HTTP 工作。 |

## 何時使用

當工作聚焦於以下任何一項時，請安裝此外掛程式：

- 在任何 CMS 平台上開發或自訂佈景主題與範本
- 建構或修改外掛程式、應用程式、模組或擴充功能
- 開發管理或編輯器介面、內容表單或發布流程
- 處理媒體上傳、資產管線或創作檔案儲存
- 實作或除錯 Markdown 轉譯與內容轉換
- 建構靜態匯出、部署或伺服器端轉譯輸出管線
- 建立內容類型模型、分類法、slug、Metadata 或遷移結構描述
