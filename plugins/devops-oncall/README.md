# DevOps On-Call 外掛模組

一組專注的提示詞、指示與聊天模式，可協助對事件進行分類，並使用 DevOps 工具與 Azure 資源快速回應。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install devops-oncall@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/devops-oncall:azure-resource-health-diagnose` | 分析 Azure 資源健康狀態，從記錄檔與遙測資料診斷問題，並為識別出的問題建立補救計畫。 |
| `/devops-oncall:multi-stage-dockerfile` | 為任何語言或架構建立最佳化的多階段 Dockerfile |

### 代理人

| 代理人 | 說明 |
|-------|-------------|
| `azure-principal-architect` | 使用 Azure 良好架構架構 (Well-Architected Framework) 原則與 Microsoft 最佳做法提供專家級的 Azure 首席架構師指引。 |

## 來源

此外掛模組是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群導向的 GitHub Copilot 擴充功能集合。
