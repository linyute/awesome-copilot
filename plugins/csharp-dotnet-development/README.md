# C# .NET Development 外掛模組

C# 與 .NET 開發必備的提示詞、指示與聊天模式，包含測試、文件與最佳做法。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install csharp-dotnet-development@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/csharp-dotnet-development:csharp-async` | 取得 C# 非同步程式設計的最佳做法 |
| `/csharp-dotnet-development:aspnet-minimal-api-openapi` | 建立包含適當 OpenAPI 文件的 ASP.NET Minimal API 端點 |
| `/csharp-dotnet-development:csharp-xunit` | 取得 XUnit 單元測試的最佳做法，包含資料驅動測試 |
| `/csharp-dotnet-development:csharp-nunit` | 取得 NUnit 單元測試的最佳做法，包含資料驅動測試 |
| `/csharp-dotnet-development:csharp-mstest` | 取得 MSTest 3.x/4.x 單元測試的最佳做法，包含現代斷言 API 與資料驅動測試 |
| `/csharp-dotnet-development:csharp-tunit` | 取得 TUnit 單元測試的最佳做法，包含資料驅動測試 |
| `/csharp-dotnet-development:dotnet-best-practices` | 確保 .NET/C# 程式碼符合方案/專案的最佳做法。 |
| `/csharp-dotnet-development:dotnet-upgrade` | 隨即可用的提示詞，用於全面的 .NET 架構升級分析與執行 |
| `/csharp-dotnet-development:resx-source-generator-migration` | 將使用已簽入 .designer.cs 檔案搭配 .resx 的專案遷移至改用原始碼產生器 |

### 代理人

| 代理人 | 說明 |
|-------|-------------|
| `expert-dotnet-software-engineer` | 使用現代軟體設計模式提供專家級的 .NET 軟體工程指引。 |
