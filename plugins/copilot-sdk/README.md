# Microsoft Copilot SDK 外掛模組

跨多種程式設計語言使用 Microsoft Copilot SDK 建構應用程式。包含 C#、Go、Node.js/TypeScript 與 Python 的完整指引，以協助您建立由 AI 支援的應用程式。

SDK 正分階段從 GitHub Copilot SDK 轉型為 Microsoft Copilot SDK。目前無需立即進行任何變更：下方的套件名稱與程式碼範例仍使用目前已發布的識別名稱。請參閱[官方轉型公告](https://github.blog/changelog/2026-10-28-github-copilot-sdk-is-becoming-microsoft-copilot-sdk/)。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install copilot-sdk@awesome-copilot
```

## 包含內容

### 技能

| 技能 | 說明 |
|-------|-------------|
| `SKILL.md` | 使用 Microsoft Copilot SDK 建置代理式應用程式。適用於在應用程式中嵌入 AI 代理、建立自訂工具、實作串流回應、管理工作階段、連線至 MCP 伺服器，或建立自訂代理。 |

## 來源

此外掛模組是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群導向的 GitHub Copilot 擴充功能集合。
