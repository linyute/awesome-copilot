# Copilot SDK 外掛模組

跨多種程式設計語言使用 GitHub Copilot SDK 建構應用程式。包含 C#、Go、Node.js/TypeScript 與 Python 的完整指引，以協助您建立由 AI 支援的應用程式。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install copilot-sdk@awesome-copilot
```

## 包含內容

### 技能

| 技能 | 說明 |
|-------|-------------|
| `SKILL.md` | 使用 GitHub Copilot SDK 建構代理型應用程式。在應用程式中嵌入 AI 代理人、建立自訂工具、實作串流回應、管理工作階段、連線至 MCP 伺服器或建立自訂代理人時使用。觸發詞包括 Copilot SDK、GitHub SDK、agentic app、embed Copilot、programmable agent、MCP server、custom agent。 |

## 來源

此外掛模組是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群導向的 GitHub Copilot 擴充功能集合。
