# OpenAPI 轉應用程式 - Java Spring Boot 外掛程式

從 OpenAPI 規格產生可用於生產環境的 Spring Boot 應用程式。包含專案 scaffolding、REST 控制器產生、服務層架構組織以及 Spring Boot 最佳做法。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install openapi-to-application-java-spring-boot@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/openapi-to-application-java-spring-boot:openapi-to-application-code` | 從 OpenAPI 規格產生完整且可用於生產環境的應用程式 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `openapi-to-application` | 從 OpenAPI 規格產生可運作應用程式的專家助手 |

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個由社群驅動的 GitHub Copilot 擴充功能集合。
