# UIZZE 外掛程式

阻止千篇一律的粗劣 UI (UI slop) 被交付。UIZZE 為 GitHub Copilot 提供了可重複的工作流程，將真實的介面佐證轉化為產品專屬的設計合約，隨後依據嚴格的完成關卡檢查結果。

## 安裝

```bash
copilot plugin install uizze@awesome-copilot
```

## 包含內容

| 技能 | 說明 |
|---|---|
| `anti-ui-slop` | 選取相關的介面參考、擷取可重複使用的設計決策、撰寫可直接實作的設計合約，並在具體性、互動狀態、回應能力、協助工具以及設計系統完整性通過審查之前阻止標記為完成。 |

## 運作方式

1. 檢查目標產品、任務以及現有的設計系統。
2. 在 [UIZZE](https://uizze.com) 的 800,000+ 個真實 Web 與 iOS 螢幕截圖公開目錄中搜尋三到五個相關範例。
3. 在實作前將佐證轉化為設計合約。
4. 執行完成關卡，並在宣告 UI 完成之前修正每一個阻礙性問題。

即使無法瀏覽目錄，此技能仍可使用：它可以依據使用者提供的參考資料或存放庫佐證運作，並會說明缺少哪些佐證。

## 需求與範圍

- 不需要帳戶、認證資料、權杖或外部伺服器。
- 此外掛程式未隨附任何 MCP 伺服器。
- 此技能採用 MIT 授權，且可獨立發揮作用。

UIZZE 維護該技能所引用的公開目錄。

若需在本外掛程式之外進行可選的獨立匿名來源檢查，可使用[免費的 UI slop 預覽](https://uizze.com/mcp/preview)。它僅提供一個確定性的 `check_ui_slop` 工具，無需帳戶或權杖，且非此外掛程式的必要條件。
