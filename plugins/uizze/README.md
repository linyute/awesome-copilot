# UIZZE 外掛程式

停止推出通用的 UI。UIZZE 協助 GitHub Copilot 建立符合產品需求的介面，並完成讓介面可用的各種狀態。

## 安裝

```bash
copilot plugin install uizze@awesome-copilot
```

## 內容

| 技能           | 說明                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| `anti-ui-slop` | 使用產品簡介和現有設計系統，載入一份專注的操作指南，視需要尋找相關介面參考，並在完成前檢查呈現結果。 |

## 運作方式

1. 檢查目標產品、工作、元件和現有設計系統。
2. 針對正在進行的介面工作類型，載入一份專注的操作指南。
3. 只有在具體的視覺問題能從中受益時，才使用 UIZZE 參考資料。
4. 可行時呈現一次，並在完成前修正可觀察到的問題。

此技能僅依賴存放庫中的證據即可運作。UIZZE 參考資料是選用項目，搜尋結果為空是正常的不作業狀態。

## 需求與範圍

- 不需要帳戶、認證資訊、權杖或外部伺服器。
- 此外掛程式未隨附 MCP 伺服器。
- 此技能採用 MIT 授權，單獨使用也很實用。

選用的獨立驗證版 UIZZE MCP 僅提供 `find_ui_references` 和 `find_ui_materials`。此外掛程式不需要它。
