# Modernization Workflow Plugin

用於視覺化並指引 GitHub Copilot Modernize CLI 之
Assess、Plan 與 Execute 工作流程的互動式畫布，適用於 .NET、Java 與 C++ 應用程式
存放庫。

## Installation

```bash
copilot plugin install modernization-workflow@awesome-copilot
```

## Source

此外掛程式為
[Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。
