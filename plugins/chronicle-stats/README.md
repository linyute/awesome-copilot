# My AI Usage 外掛程式

依日期、模型與工作階段檢視您本機的 Copilot Token 使用量，並取得更具效率的使用提示。

## 需求

- 支援畫布（canvas）的 GitHub Copilot 應用程式
- Node 22.13+（此擴充功能使用 `node:sqlite`，無法在舊版 Node 上載入）

## 安裝

```bash
copilot plugin install chronicle-stats@awesome-copilot
```

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。
