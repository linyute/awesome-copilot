# PHP MCP 伺服器開發外掛程式

使用官方 PHP SDK 搭配基於屬性的探索建構 Model Context Protocol 伺服器的完整資源，包括最佳做法、專案產生以及專家協助

## 安裝

```bash
# Using Copilot CLI
copilot plugin install php-mcp-development@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/php-mcp-development:php-mcp-server-generator` | 使用官方 PHP SDK 產生具有工具、資源、提示和測試的完整 PHP Model Context Protocol 伺服器專案 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `php-mcp-expert` | 使用官方 PHP SDK 搭配基於屬性的探索進行 PHP MCP 伺服器開發的專家助手 |

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個由社群驅動的 GitHub Copilot 擴充功能集合。
