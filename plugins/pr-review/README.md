# PR Review 外掛程式

在唯讀畫布中檢閱 GitHub 提取請求（pull request）。Copilot 會根據路徑與
Metadata 將相關的變更檔案分組、顯示完整的可展開
Diff，並回答限定於群組、檔案或程式碼片段（hunk）範圍的問題。檢閱快照
與回答會保留在目前的工作階段中。

## 安裝

```bash
copilot plugin install pr-review@awesome-copilot
```

## 來源

此外掛程式是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。
