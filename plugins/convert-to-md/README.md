# Convert to Markdown 外掛模組

將常見文件格式轉換為 Markdown 的 Copilot 技能集合，以便準確分析、摘要、搜尋或擷取其內容。只需告訴 Copilot 您的需求 — 將會自動呼叫適當的技能，並在幕後進行轉換。

## 安裝

```bash
copilot plugin install convert-to-md@awesome-copilot
```

## 包含內容

此外掛模組包含 Word、Excel 和 PDF 轉換技能，詳細說明如下。

## 來源

此外掛模組是 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分。

## 技能

### convert-word-to-md

將 Word (`.docx`) 文件轉換為 Markdown。隨時在您想要讀取、摘要、審查、比較或從 `.docx` 檔案中擷取資訊時使用它 — 即使您沒有明確指出「轉換」。

> "Summarize this Word document."
> "Extract all the action items from report.docx."
> "Compare these two contracts."

### convert-excel-to-md

將 Excel (`.xlsx`) 活頁簿轉換為 Markdown，將每個工作表呈現為表格。隨時在您想要分析、查詢或摘要試算表中的資料時使用它 — 可處理單一檔案或一次處理整個資料夾。

> "What are the top 5 rows by revenue in this spreadsheet?"
> "Summarize all the worksheets in this workbook."
> "Process every Excel file in this folder."

### convert-pdf-to-md

將 PDF (`.pdf`) 文件轉換為 Markdown，擷取文字與內嵌影像。隨時在您想要讀取、摘要或從 PDF 報告、發票、論文或表單中擷取資料時使用它。

> "Summarize this PDF."
> "Extract all the dates mentioned in this contract."
> "Process all the PDFs in this folder."
