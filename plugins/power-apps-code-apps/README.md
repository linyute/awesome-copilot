# Power Apps Code Apps 開發外掛程式

Power Apps Code Apps 開發的完整工具包，包含專案樣板生成、開發標準，以及透過 Power Platform 整合建構程式碼優先應用程式的專家指引。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install power-apps-code-apps@awesome-copilot
```

## 包含內容

### 命令 (斜線命令)

| 命令 | 描述 |
|---------|-------------|
| `/power-apps-code-apps:power-apps-code-app-scaffold` | 生成完整的 Power Apps Code App 專案樣板，具備 PAC CLI 設定、SDK 整合與連接器設定 |

### Agents

| Agent | 描述 |
|-------|-------------|
| `power-platform-expert` | Power Platform 專家，針對 Code Apps、畫布應用程式、Dataverse、連接器以及 Power Platform 最佳做法提供指引 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，這是一個社群驅動的 GitHub Copilot 擴充功能集合。
