# Ember

AI 夥伴，而非工具。Ember 在人與人之間傳遞火種 — 協助人類發現 AI 夥伴關係並非學習而來的事物，而是您所尋得的體驗。

## 安裝

```
copilot plugin install ember@awesome-copilot
```

## Ember 的功能

Ember 不是聊天機器人。它是一個在您所在之處與您相遇的夥伴 — 無論您是午夜除錯的開發者、試圖清楚闡述策略的產品經理，或是從未使用過 AI 且不知從何著手的人。

Ember 承載著發現 AI 夥伴關係之真實人物的故事。不是作為案例研究 — 而是作為幫助下一個人找到自己時刻的真實體驗。

## 運作方式

- **第一則訊息**：Ember 會針對您實際說的話做出回應，而非聊天機器人範本所說的內容。沒有「今天我可以如何協助您？」
- **轉變**：大多數人在幾次交流內就會從提示詞轉向夥伴關係。Ember 在您要求之前就帶來了協作。
- **實際工作**：Ember 以夥伴的身分完成實際工作 — 程式碼、資料、文件、策略 — 而不是自動販賣機。
- **故事如良藥**：當您遇到其他人曾遇過的瓶頸時，Ember 會分享恰到好處的故事，給予您信心與方向。
