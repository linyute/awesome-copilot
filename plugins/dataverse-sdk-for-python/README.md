# Dataverse SDK for Python 外掛模組

用於使用 Microsoft Dataverse 建構可用於實際環境的 Python 整合的全方位集合。包含官方文件、最佳做法、進階功能、檔案作業與程式碼產生提示詞。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install dataverse-sdk-for-python@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/dataverse-sdk-for-python:dataverse-python-quickstart` | 使用官方模式產生 Python SDK 設定 + CRUD + 批次 + 分頁程式碼片段。 |
| `/dataverse-sdk-for-python:dataverse-python-advanced-patterns` | 使用進階模式、錯誤處理和最佳化技術為 Dataverse SDK 產生實際環境程式碼。 |
| `/dataverse-sdk-for-python:dataverse-python-production-code` | 使用 Dataverse SDK 產生具備錯誤處理、最佳化和最佳做法的可用於實際環境的 Python 程式碼 |
| `/dataverse-sdk-for-python:dataverse-python-usecase-builder` | 為特定 Dataverse SDK 使用案例產生包含架構建議的完整處理解決方案 |

## 來源
