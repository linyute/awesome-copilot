# Automate This

你是否遇過每週都要做的那件事 — 那個需要點擊十五次、橫跨四個應用程式、複製貼上到試算表然後透過電子郵件寄出的流程，讓你很想把筆記型電腦丟進海裡？只要將自己操作的過程錄製一次，把影片交給 Copilot CLI，讓它為你撰寫自動執行的指令碼。

## 運作方式

1. **錄製你的螢幕畫面。** 使用 QuickTime、OBS、Loom 或任何你現有的工具。完全按照平常的方式執行該流程。如果你想在錄製時邊操作邊說明（「現在我正在下載這份報表，因為財務部門每週一都需要它」），那就更好了 — 此外掛程式會轉錄你的旁白，並用它來理解你執行每個步驟的*原因*，而不僅僅是你點擊了*什麼*。

2. **將錄影檔案放在桌面上**（或任何位置 — 只需要一個檔案路徑）。

3. **指示 Copilot CLI 進行分析：**
   ```
   copilot
   > /skills
   > (select automate-this)
   > Analyze ~/Desktop/weekly-report-process.mov and automate it
   ```

4. **檢閱其分析結果。** 此外掛程式每隔幾秒從影片中擷取影格、轉錄所有旁白語音，並將你的流程重構為編號步驟清單。在提出任何建議之前，它會請你確認內容是否正確。

5. **選擇你的自動化等級。** 你將獲得最多三種方案建議，範圍從「處理最繁瑣部分的一行指令」到「具備排程和錯誤處理的完整指令碼」。每種方案都使用你已安裝的工具 — 不會有出乎意料的相依性套件鏈。

## 底層運作原理

此外掛程式使用 `ffmpeg` 從你的錄影中擷取影格與音訊。若你有錄製旁白，它會使用 OpenAI 的 Whisper（於你的本機電腦上執行，而非雲端）來轉錄所說的內容。擷取出的影格會傳送給 AI 模型，該模型能夠讀取螢幕上的文字、識別應用程式、檢視你正在點擊的內容，並跟隨流程的脈絡。

在提出自動化建議之前，此外掛程式會檢查你的環境 — 已安裝的項目、使用的 shell、可用的指令碼語言 — 因此它只會提出你無需耗費一小時設定即可實際執行的建議。

## 先決條件

- **ffmpeg**（必要）— 用於從錄影檔案中擷取影格與音訊
  ```bash
  brew install ffmpeg
  ```

- **Whisper**（選用）— 僅在錄影內容包含旁白語音時才需要
  ```bash
  pip install openai-whisper
  ```
  或是 C++ 版本：`brew install whisper-cpp`

若未安裝 Whisper 且錄影檔案包含音訊，此外掛程式會通知你，並詢問是否僅以純視覺方式繼續進行分析。

## 安裝

```bash
copilot plugin install automate-this@awesome-copilot
```

## 適合分析的情境

當錄影能清楚展示操作過程時，此外掛程式的效果最好。使用者運用此工具自動化的一些流程範例包括：

- **報表產生** — 從儀表板下載資料、篩選、格式化並傳送給他人
- **檔案整理** — 將下載檔案分類至資料夾、依日期重新命名檔案、清理重複檔案
- **資料輸入** — 從一個應用程式複製資訊並輸入到另一個應用程式
- **開發環境設定** — 每次啟動新專案時執行的指令與設定變更序列
- **重複性終端機工作流程** — 使用不同輸入執行相同的指令序列
- **以電子郵件為基礎的工作流程** — 從電子郵件擷取資料、處理並回覆結果

## 保持手動的部分

此外掛程式針對機械化步驟提出自動化建議。它保留了人類的判斷 — 如果錄影顯示你暫停下來檢閱某個項目，或是根據所見內容做出決策，則該步驟在自動化中仍會維持手動，並提示你輸入。

## 範例

假設你錄製了自己執行每週任務的過程：你打開瀏覽器、導覽至內部儀表板、下載三個 CSV 匯出檔、在 Excel 中開啟各檔案、篩選標記為「pending」的資料列、合併至單一工作表，然後用電子郵件寄給主管。

此外掛程式會重構該流程，與你確認後提出類似以下的建議：

- **等級 1：** 一個 `curl` 指令，一次下載全部三個 CSV（若儀表板有直接下載 URL），完全略過瀏覽器。
- **等級 2：** 一個 Python 指令碼，負責下載 CSV、使用 pandas 篩選「pending」列、合併資料並儲存結果 — 隨時可附加至電子郵件中。
- **等級 3：** 相同的指令碼，加上透過你的郵件用戶端自動發送電子郵件，並透過 `launchd` 於每週一早上 8 點執行。

每個等級都包含可運作的程式碼、透過模擬測試（dry run）進行驗證的指示，以及在發生異常時的回滾復原方式。

## 隱私權

影格擷取（ffmpeg）與音訊轉錄（Whisper）完全在你的本機電腦上執行。擷取出的影格與音訊會寫入安全的暫存目錄中，並在分析完成後予以刪除。擷取的影格與轉錄文字會傳送給驅動 Copilot CLI 工作階段的 AI 模型進行分析 — 這與所有 Copilot 互動使用的是相同的模型和資料管線。除 Copilot 原本使用的服務外，不會將資料傳送至任何額外的第三方服務。
