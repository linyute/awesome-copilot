# Frontend Web Development 外掛模組

現代前端網頁開發必備的提示詞、指示與聊天模式，包含 React、Angular、Vue、TypeScript 與 CSS 架構。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install frontend-web-dev@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/frontend-web-dev:playwright-explore-website` | 使用 Playwright MCP 進行測試導向的網站探索 |
| `/frontend-web-dev:playwright-generate-test` | 使用 Playwright MCP 根據情境產生 Playwright 測試 |

### 代理人

| 代理人 | 說明 |
|-------|-------------|
| `expert-react-frontend-engineer` | 專精於現代 Hook、Server Component、Action、TypeScript 與效能最佳化的專家級 React 19.2 前端工程師 |
| `electron-angular-native` | 專為具有 Node.js 後端 (main)、Angular 前端 (render) 與原生整合層（例如 AppleScript、Shell 或原生工具）的 Electron 應用程式量身打造的程式碼審查模式。此處不審查其他存放庫中的服務。 |

## 來源
