# Phoenix 外掛程式

適用於 LLM 應用程式偵錯、評估與追蹤的 Phoenix AI 可觀測性技能。包含 CLI 偵錯工具、LLM 評估工作流程與 OpenInference 追蹤檢測。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install phoenix@awesome-copilot
```

## 內含項目

### 技能 (Skills)

| 技能 | 說明 |
|-------|-------------|
| `phoenix-cli` | 使用 Phoenix CLI 偵錯 LLM 應用程式。擷取追蹤、分析錯誤、檢視實驗、檢查資料集，以及查詢 GraphQL API。 |
| `phoenix-evals` | 使用 Phoenix 為 AI/LLM 應用程式建構並執行評估器。 |
| `phoenix-tracing` | 適用於 Phoenix AI 可觀測性的 OpenInference 語意慣例與檢測。 |
