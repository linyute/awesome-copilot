# Swift MCP Server Development 外掛程式

使用官方 MCP Swift SDK 搭配現代並行功能的完整集合，專為在 Swift 中建構 Model Context Protocol 伺服器而設計。

## 安裝

```bash
# 使用 Copilot CLI
copilot plugin install swift-mcp-development@awesome-copilot
```

## 包含內容

### 指令 (斜線指令)

| 指令 | 說明 |
|---------|-------------|
| `/swift-mcp-development:swift-mcp-server-generator` | 使用官方 MCP Swift SDK 套件在 Swift 中產生完整的 Model Context Protocol 伺服器專案。 |

### Agent

| Agent | 說明 |
|-------|-------------|
| `swift-mcp-expert` | 專家級協助，協助使用現代並行功能與官方 MCP Swift SDK 在 Swift 中建構 Model Context Protocol 伺服器。 |

## 來源

此外掛程式為 [Awesome Copilot](https://github.com/github/awesome-copilot) 的一部分，該專案為社群推動的 GitHub Copilot 擴充套件集合。
