# Java 開發外掛程式

包含適用於 Java 開發（包括 Spring Boot、Quarkus、測試、文件與最佳做法）的完整提示與指示集合。

## 安裝

```bash
# Using Copilot CLI
copilot plugin install java-development@awesome-copilot
```

## 內含項目

### 指令 (Slash Commands)

| 指令 | 說明 |
|---------|-------------|
| `/java-development:java-docs` | 確保 Java 類別使用 Javadoc 註解進行記載，並遵循文件的最佳做法。 |
| `/java-development:java-junit` | 取得 JUnit 5 單元測試的最佳做法，包括資料驅動測試 |
| `/java-development:java-springboot` | 取得使用 Spring Boot 開發應用程式的最佳做法。 |
| `/java-development:create-spring-boot-java-project` | 建立 Spring Boot Java 專案架構 |
